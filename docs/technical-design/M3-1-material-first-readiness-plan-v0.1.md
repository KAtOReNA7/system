# M3-1 物料优先 readiness 设计计划 v0.1

生成日期：2026-06-28

状态：设计计划。本文件只定义 M3-1 的最小闭环，不实现代码、不写 migration、不读取 private 物料。

## 1. 目标

M3-1 应围绕“private 选题物料 -> 字段抽取/候选 -> 用户确认 -> 核心 readiness -> 渠道级点值预测输入准备”建立最小闭环。

结构化选题表不是主入口，只作为少数缺少完整物料的补充入口。

## 2. 最小闭环

1. 接收本地 private 物料路径或人工输入摘要。
2. 判断物料类型：Word、PDF、PPT、物料表、手工文本。
3. 抽取或登记字段候选。
4. 自动确认低风险明确字段。
5. 将分类、版权期、关键热度解释、对标、预测输入判断送入人工确认。
6. 计算核心 readiness。
7. 若核心字段齐备，进入本地非正式候选评估准备。
8. 若核心字段缺失，输出缺口清单，不生成 numeric forecast。

## 3. 字段确认分层

| 层级 | 字段类型 | 处理 |
|---|---|---|
| 自动确认候选 | 标题、作者、来源、字数、完结状态等明确事实字段 | 来源可追溯且唯一时可自动确认 |
| 必须人工确认 | 分类、版权期、关键热度解释、对标、预测输入判断 | 不得自动确认 |
| 可选解释字段 | 评论量、改编信号、材料来源、材料更新时间、备注 | 缺失不阻断 numeric forecast，但影响解释 |

## 4. 核心 readiness gate

| 字段组 | 阻断条件 |
|---|---|
| 身份 | 缺标题、作者或来源 |
| 分类 | 缺用户确认后的分类 |
| 热度 | 缺任何可用热度信号或热度摘要 |
| 版权期 | 缺版权期限范围或可开发窗口 |

非核心字段缺失时，不应阻断 numeric forecast，只输出风险或解释限制。

## 5. 预测输入准备

M3-1 不直接实现预测模型，但必须为后续 M3-2 准备如下输入：

- 目标渠道列表；
- 每个渠道可用热度/转化依据；
- 渠道级点值预测所需字段；
- 五年累计、首年、第 1-5 年拆分所需字段；
- 新品候选评级所需字段；
- 改编信号与风险解释字段。

## 6. 输出边界

M3-1 可以输出：

- 字段候选；
- 自动确认字段；
- 待人工确认字段；
- readiness 状态；
- 缺口清单；
- 预测输入准备状态。

M3-1 不输出：

- 是否建议开发；
- 资源投入等级；
- 正式收入预测；
- 正式评级；
- 正式 task/export/write API。

## 7. 测试计划

后续实现时至少需要：

- 物料字段抽取 fixture 测试；
- 自动确认白名单测试；
- 分类不得自动确认测试；
- 核心 readiness 阻断测试；
- 非核心字段缺失不阻断测试；
- 结构化选题表补充入口测试；
- 不输出开发建议测试；
- 不输出资源等级测试；
- 不读取或提交 private 物料测试。

## 8. 安全边界

- private 物料只允许本地读取，不能提交。
- 公开仓库只允许提交规则、模板、脱敏 summary 和测试。
- 本阶段不连接远端生产、共享、staging-like 或未授权数据库。
- 本阶段不进入 M3 formal execution。
