## 3. checker 读取范围

checker 固定使用 allowlist，只读取以下公开输入类型：

- M2-B-3 前置授权公开报告；
- M2-B-3 前置授权 summary JSON；
- M2-B-3 readiness design 公开报告；
- M2-B-3 readiness design summary JSON；
- M2-B fixture 阶段收口报告和 summary JSON；
- M2-B-1 / B-2 / B-2.1 公开实现报告；
- M2 老品评估 API 契约和 addendum；
- M2 老品评估 PRD；
- fixture/synthetic 文件；
- `package.json`。

checker 不递归扫描仓库，不扫描 `data/**`，不读取 stage JSON，不读取 `.env`、`.env.local` 或 `.pgpass`。

## 4. checker 禁止范围

checker 禁止：

- 连接任何数据库；
- 执行 Docker；
- 调用网络；
- 读取 `data/**`；
- 读取真实账单；
- 读取数字版权台账；
- 读取运营确认 Excel；
- 读取运营确认结果；
- 读取 `mapping_import_stage-v0.1.json`；
- 读取 `mapping_import_stage-v0.2.json`；
- 读取私有候选包本体；
- 读取数据库连接串；
- 读取 `.env.local`；
- 修改任何输入文件；
- 激活 `mapping_version`；
- 调用 `switch_mapping_version`；
- 执行正式数据迁移。

## 6. 输出 JSON

命令：

```bash
npm run check:m2-b3:no-db-readiness
```

成功时：

- stdout 输出 JSON；
- `status=pass`；
- `mode=no-db`；
- `stage=M2-B-3.1`；
- exit code 为 0。

失败时：

- stdout 输出 JSON；
- `status=fail`；
- `findings` 包含 `code`、`severity`、`message`；
- exit code 非 0；
- 不输出连接串、密钥、SQL、stack trace、真实业务明细或私有路径。
