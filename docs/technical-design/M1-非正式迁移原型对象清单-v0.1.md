## 2. 核心函数

业务入口：

- `derive_standard_work_id(text)`；
- `derive_business_form(text)`；
- `begin_master_data_initialization(text)`；
- `initialize_bootstrap_versions(text)`；
- `activate_bill_batch(bigint,bigint,text)`；
- `revoke_bill_batch(bigint,bigint,text)`；
- `switch_mapping_version(bigint,text)`；
- `switch_basic_info_version(bigint,text)`。

内部校验与触发器函数包括：映射覆盖检查、生命周期 active 数量检查、版本状态保护、快照子表冻结、事实不可变、跨表映射互斥、分类父级连续性、基础信息 release 一致性和投影来源一致性。M1 schema 函数合计 21。
