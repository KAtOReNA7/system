# M2-B-2.1 老品评估 fixture-only 页面交互细化与 API 契约补充报告 v0.1

## 1. 本轮范围

本轮是 M2-B-2.1，不是 M2-B-3。目标是基于 M2-B-1 fixture-only API 和 M2-B-2 管理端页面，补强只读页面交互、状态表达、API 契约 addendum 和测试覆盖。

本轮未做：

- persistence；
- database repository；
- migration；
- Docker；
- formal mode；
- `local_dry_run` mode；
- export API；
- evaluation task create/cancel/retry；
- write API；
- mapping activation；
- `switch_mapping_version`。

## 2. 页面交互增强

### 2.1 总览页

增强点：

- rating / lifecycle / risk 分布项变为可点击筛选入口；
- 点击后跳转到 `#m2-list`；
- 列表页通过 M2-B-1 fixture API 带对应 query 参数重新请求；
- 保持 `fixture-only`、`synthetic marker`、formal blocked 和 `2026-05 excluded` 提示常驻。

### 2.2 列表页

增强点：

- 新增 `risk` 筛选；
- 新增 `resultStatus` 筛选；
- 保留 `query`、`rating`、`lifecycle`、`readiness`、`sort`、`page`、`pageSize`；
- 新增 `Reset filters`；
- 新增 `View detail` 显式详情入口；
- empty 状态展示当前筛选摘要；
- 筛选和重置均通过 M2-B-1 fixture API 请求，不通过前端隐藏全集绕过 API。

### 2.3 详情页

增强点：

- 支持从列表 `View detail` 进入指定 `standardWorkId`；
- 支持不存在作品的 `not_found` 状态；
- 新增 `Back to evaluation list`；
- 展示 current / historical / invalidated 的状态说明；
- input snapshot 明确标记 `fixture-only=true`；
- forecast scenarios 明确展示 base / optimistic / pessimistic 结构；
- risks 和 suggestions 保持分组展示。

### 2.4 数据缺口页

增强点：

- 新增 `gapCode` 筛选；
- 新增 `severity` 筛选；
- 保留 `readiness`、`page`、`pageSize`；
- 新增 `Reset gap filters`；
- 展示 `blocksFormalEvaluation`；
- 展示 `suggestedOwnerAction`；
- 增加 formal blocking reasons 说明；
- 不提供任何修复、导入、应用、激活按钮。

### 2.5 回测与算法版本页

增强点：

- 新增 backtest batch 选择器；
- 支持通过 `GET /api/m2/old-products/backtests/{backtestBatchId}` 展示 detail；
- 展示 `covered`、`missed`、`over`、`under`；
- 展示 `fixtureOnly=true`；
- 增加 formal backtest blocked 提示。

## 3. API 契约补充

新增：

- `docs/api/M2-old-product-evaluation-api-contract-addendum-v0.1.md`

补充内容：

- 页面交互依赖的 list query 参数；
- list 筛选、排序、重置行为；
- detail route 与 `not_found` 行为；
- readiness gap 的 `gapCode` / `severity` / `readiness` 筛选；
- backtest detail 行为；
- blocked / empty / error / not_found 状态响应约定；
- fixture-only dataset 标识；
- formal mode 阻断；
- 不实现 evaluation task、export、formal、local_dry_run、write API。

## 4. API 实现变更

本轮未新增 API 端点。

本轮只对现有 fixture repository 做最小只读补强：

- `GET /api/m2/old-products/readiness-gaps` 支持 `gapCode`；
- `GET /api/m2/old-products/readiness-gaps` 支持 `severity`；
- gap row 增加 `blocksFormalEvaluation`；
- gap row 增加 `suggestedOwnerAction`。

未变更：

- formal mode 仍返回 `formal_data_blocked`；
- unknown work 仍返回 `not_found`；
- invalid query 仍返回 `bad_request`；
- task/export/write endpoints 仍不可用。

- task/export/write endpoints 不可用；

- E2E：backtest batch detail；

## 6. 安全边界

本轮确认：

- 不连接数据库；
- 不执行 Docker；
- 不读取 `data/**`；
- 不读取真实账单；
- 不读取数字版权台账；
- 不读取运营确认 Excel；
- 不读取运营确认结果；
- 不读取 `mapping_import_stage-v0.1.json`；
- 不读取 `mapping_import_stage-v0.2.json`；
- 不导入真实数据；
- 不激活 `mapping_version`；
- 不调用 `switch_mapping_version`；
- 不执行正式数据迁移；
- 不修改 `db/migrations/`；
- 不新增 write API；
- 不新增 formal mode；
- 不新增 `local_dry_run` mode；
- 不新增 export API；
- 不新增 evaluation task API。

## 7. 阶段结论

M2-B-2.1 fixture-only 页面交互细化与 API 契约补充已完成。

M2-B-3 继续暂缓，除非后续明确授权并继续保持 fixture-only 边界。
