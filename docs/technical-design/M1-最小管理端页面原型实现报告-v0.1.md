# M1 最小管理端页面原型实现报告 v0.1

状态：COMPLETED

日期：2026-06-21

## 1. 本轮范围

本轮基于以下文档实现最小只读管理端原型：

- `docs/product/M1-minimal-admin-pages-v0.1.md`
- `docs/api/M1-api-contract-v0.1.md`

实现目标：

- 系统状态页；
- 作品列表页；
- 映射版本页；
- 后台任务页；
- loading / empty / success / degraded / error / not found 状态；
- 当前只读 API 调用；
- 前端内存合成 fixture 模式。

## 2. 实现方式

沿用现有 Node.js 原生 HTTP 服务，不引入前端框架。

新增静态入口：

```text
GET /admin
GET /admin/
GET /admin/app.css
GET /admin/app.js
```

静态文件：

- `public/admin/index.html`
- `public/admin/app.css`
- `public/admin/app.js`

服务端静态资源模块：

- `src/http/staticAdmin.js`

## 3. 页面说明

### 3.1 系统状态

调用：

- `GET /health`
- `GET /health/db`
- `GET /api/system/status`

展示：

- 服务状态；
- 数据库状态；
- schema version；
- system state；
- `mappingVersionReady`；
- `billImportReady`。

### 3.2 作品列表

调用：

- `GET /api/works`
- `GET /api/works/:id`

展示：

- 标准作品 ID；
- 基础信息记录缺失状态；
- 核心字段缺失状态；
- 分类缺失状态；
- 分页信息；
- 详情预览。

不展示真实收入数据。

### 3.3 映射版本

调用：

- `GET /api/mapping-versions`
- `GET /api/mapping-versions/:id`

展示：

- version id；
- versionNo；
- status；
- triggerType；
- projectionRowCount；
- createdAt；
- 是否 active。

不提供激活、导入、撤销或应用按钮。

### 3.4 后台任务

调用：

- `GET /api/jobs`
- `GET /api/jobs/:id`

展示：

- job id；
- job type；
- logicalOperationKey；
- status；
- createdAt；
- finishedAt；
- 详情预览。

不提供启动、重试或取消按钮。

## 4. 合成 fixture 模式

页面提供“使用合成 fixture”开关。该模式只使用前端内存中的虚构数据：

- `SYN-WORK-001`
- `SYN-WORK-002`
- `SYN-JOB-001`
- `synthetic_fixture`

该模式不读取 `data/`，不连接正式数据库，不导入真实数据。

## 5. 状态覆盖

已实现：

- `loading`：请求中；
- `empty`：空库返回空列表；
- `success`：API 或 fixture 返回数据；
- `degraded`：`/health/db` 返回降级状态；
- `error`：API 请求失败；
- `not found`：详情 ID 不存在。

空库状态作为正常状态处理。
