## 2. 当前实现范围

本轮只实现 M1 最小只读模块：

- 系统状态模块；
- 作品主数据只读模块；
- 映射版本只读模块；
- 后台任务只读抽象；
- 统一错误响应；
- 合成 fixture 测试边界。

所有业务 API 当前均为只读。没有新增任何真实导入接口、写接口、版本激活接口或后台任务启动接口。

## 3. 当前不在范围内

本轮明确不实现：

- 真实账单导入；
- 数字版权台账导入；
- 运营确认 Excel 导入；
- 运营确认结果自动应用；
- 候选或正式 `mapping_version` 导入；
- 映射版本激活；
- 批次激活或撤销；
- 收入预测；
- 复杂筛选；
- 正式数据库连接；
- 正式数据迁移。

## 4. 角色使用边界

| 模块 | 使用角色 | 说明 |
| --- | --- | --- |
| `/api/works` | `application_ro` | 读取 `m1.v_basic_info_gap` 视图 |
| `/api/system/status` | `background_worker` | 读取 `m1.system_state`、active 映射版本和 active 批次状态 |
| `/api/mapping-versions` | `background_worker` | 只读查询映射版本元数据 |
| `/api/jobs` | `background_worker` | 只读查询后台任务元数据 |
| 普通应用运行 | 不得使用 `migration_owner` | `migration_owner` 仅用于 Flyway 迁移 |

本轮不使用 `application_rw` 写业务数据。`application_rw` 只保留给未来普通业务读写接口，但仍不得直接修改 `income_fact`。

## 5. 空库行为

在已初始化但未导入真实数据的空库中：

- `/api/system/status` 返回 `schema_initialized`；
- `mappingVersionReady=false`；
- `billImportReady=false`；
- `/api/works` 返回空列表；
- `/api/mapping-versions` 返回空列表；
- `/api/jobs` 返回空列表；
- `/api/works/:id`、`/api/mapping-versions/:id`、`/api/jobs/:id` 对不存在资源返回统一 404。

## 6. 统一错误响应

统一格式：

```json
{
  "error": {
    "code": "not_found",
    "message": "Resource not found",
    "requestId": "..."
  }
}
```

覆盖：

- 400：参数错误；
- 404：资源不存在或路由不存在；
- 500：未预期异常；
- 503：数据库未配置等可恢复降级状态。

错误响应不得暴露：

- 数据库连接串；
- 用户名/密码；
- SQL 全文；
- 堆栈；
- 主机端口细节；
- 真实业务数据。

## 7. 合成 fixture 规则

测试 fixture 位于：

```text
test/fixtures/
```

规则：

- 只能使用虚构作品 ID、任务、映射版本和状态；
- 不使用真实作品名；
- 不使用真实渠道名；
- 不使用真实作者；
- 不使用真实金额明细；
- 不使用真实版权日期；
- 不从真实账单、台账或运营确认包复制样本。
