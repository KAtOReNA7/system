# M1 最小管理端页面状态表达与文案归一化小修订报告 v0.1

状态：IMPLEMENTED AND VERIFIED

日期：2026-06-21

## 1. 修订范围

本轮仅修订 M1 最小只读管理端页面的状态表达、错误文案、状态说明和表格提示。

未变更范围：

- 不新增写接口；
- 不新增导入、激活、撤销、重试、取消按钮；
- 不连接正式数据库；
- 不读取或导入真实账单、数字版权台账、运营确认 Excel 或运营确认结果；
- 不修改 `db/migrations/`；
- 不修改 Flyway 历史迁移。

## 2. 核心修订

### 2.1 区分空库和未配置数据库

本轮明确区分：

- 空库：数据库存在、迁移完成、业务表暂无数据，是正常状态；
- 未配置数据库：应用没有可用 DB URL，是开发环境降级状态。

默认未配置数据库时，系统状态页显示：

- 页面状态：`降级 / degraded`；
- notice：数据库未配置，这是本地开发降级状态，不等同于空库；
- 数据库卡片：`数据库未配置（database_not_configured）`；
- `schemaVersion` 与 `systemState`：暂不可读取。

### 2.2 生命周期不可读状态领域化

生命周期状态不再显示为通用“请求失败”。

未配置数据库时，生命周期卡片显示：

- 标题：生命周期状态；
- 状态：暂不可读取；
- 原因：数据库未配置（database_not_configured）；
- 技术码：database_not_configured；
- requestId。

### 2.3 错误态文案去技术化

错误态主文案改为业务可读表达。

页面仍保留：

- 技术 code；
- requestId。

页面不展示：

- 连接串；
- 密码；
- SQL 全文；
- 堆栈；
- 主机端口；
- 真实业务数据。

## 3. 状态说明归一化

页面状态增加中文说明：

| 状态 | 展示 | 说明 |
| --- | --- | --- |
| `loading` | 加载中 / loading | 正在读取本页只读信息 |
| `success` | 正常 / success | 请求成功，当前展示的是只读结果 |
| `degraded` | 降级 / degraded | 依赖未满足或不可用；页面仍保持只读可访问 |
| `empty` | 空状态 / empty | 请求成功但暂无数据；空库时这是正常状态 |
| `error` | 错误 / error | 请求失败；请根据技术码排查 |
| `not found` | 未找到 / not found | 目标记录不存在，未产生任何写入 |

技术状态增加中文展示并保留原始 code，例如：

- `schema_initialized` → 结构已初始化（schema_initialized）；
- `database_not_configured` → 数据库未配置（database_not_configured）；
- `database_unavailable` → 数据库不可用（database_unavailable）；
- `building` → 构建中（building）；
- `active` → 已启用（active）；
- `pending` → 等待中（pending）；
- `running` → 运行中（running）；
- `blocked` → 已阻断（blocked）；
- `succeeded` → 已成功（succeeded）；
- `failed` → 已失败（failed）；
- `cancelled` → 已取消（cancelled）。

## 4. 业务说明补充

作品列表增加字段说明：

- “未提供”表示当前 API 尚未返回标准作品名称；
- “缺失”表示该字段仍待基础信息补全；
- 当前不展示真实收入、作者或版权日期。

映射版本增加状态说明：

- 构建中（building）：版本仍在构建中，仅可查看，不可激活；
- 已启用（active）：当前启用版本；本页面仍不提供切换操作；
- 已失败（failed）：版本构建或校验失败，需要技术排查；
- 已退役（retired）：历史版本，仅用于追溯。

后台任务增加状态说明：

- 等待中（pending）：当前页面不提供启动或重试；
- 运行中（running）：仅展示状态；
- 已阻断（blocked）：需要按任务来源排查；
- 已成功（succeeded）：已成功完成；
- 已失败（failed）：需要查看后续诊断信息；
- 已取消（cancelled）：已取消。
