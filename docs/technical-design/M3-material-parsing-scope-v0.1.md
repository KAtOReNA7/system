# M3 物料解析范围 v0.1

生成日期：2026-06-28

状态：M3-0 planning only。本文定义 Word/PDF/PPT/物料表/手动录入可解析字段和安全边界，不实现解析器。

## 1. 总原则

- 原始材料只允许本地 private 使用。
- 不提交原始 Word/PDF/PPT/Excel/CSV。
- 不提交原文片段、完整作品明细或 private 字段抽取明细。
- 解析只产出候选字段，不自动确认。
- 人工确认后才可进入 evaluation candidate。

## 2. Word / 物料表

可解析候选字段：

| 字段 | 说明 |
|---|---|
| 书名 | 来自标题、表格“作品名/书名/选题名” |
| 作者 | 来自表格或正文作者字段 |
| 来源 | 来自频道、来源、平台、作品类型描述 |
| 简介 | 来自一句话简介、故事内容、内容简介 |
| 字数 | 来自字数字段 |
| 完结状态 | 来自状态、完结状态 |
| 阅读量/收藏量/评分/评论量 | 来自数据成绩或平台数据描述 |
| 同名有声状态 | 来自同名有声字段或人工补录 |
| 改编信号 | 来自影视、动漫、漫画、游戏等说明 |
| 站外热度 | 来自粉丝、榜单、站外热度、传播数据 |
| 目标渠道 | 来自意向平台、目标渠道 |
| 版权期限范围 | 来自签约条件、授权期限、版权期 |
| 运营推荐理由 | 来自核心优势、项目目的、项目分析 |
| 材料来源/更新时间 | 来自文件元数据或人工补录 |

限制：

- 大段原文、样章、剧情正文不得写入公开报告。
- 表格抽取结果只作为候选，需要人工确认。

## 3. PDF

可解析候选字段：

- 标题、作者、简介、目录/章节摘要；
- 字数或页数估算；
- 出版物信息；
- 宣传文案中的改编信号；
- 文件元数据和更新时间。

限制：

- PDF 原文不得提交。
- OCR 或抽取结果不得自动确认。
- 如果无法稳定提取结构化字段，只生成材料解析缺口。

## 4. PPT

可解析候选字段：

- 封面标题和作者；
- 项目定位、核心卖点、运营推荐理由；
- 数据成绩截图中的候选指标；
- 目标渠道和发布设想；
- 改编信号和外部热度描述。

限制：

- 图片、截图和幻灯片原文不得提交。
- 截图中的数据必须人工确认。

## 5. 手动录入

手动录入可覆盖所有输入字段，但必须保留确认人、确认时间和来源说明。手动录入字段可直接进入 confirmed input，但仍需通过 readiness 校验。

## 6. 候选到确认流程

1. private 材料进入本地解析。
2. 系统产出候选字段和缺口清单。
3. 用户确认、修正或补录字段。
4. 确认后的结构化输入进入 evaluation candidate。
5. 缺必填字段时，readiness blocked，不生成 numeric forecast。

## 7. 安全边界

- 本阶段不连接数据库。
- 本阶段不写 migration。
- 本阶段不写业务代码。
- 本阶段不进入 M3 formal execution。
- 本阶段不提交 private 材料或解析明细。

## 8. 用户答复后的解析范围修订

- 物料解析是 M3 第一入口。
- 物料字段不固定，不要求每份材料具备完全相同字段。
- 解析结果必须支持 `extractedFields`、`missingFields`、`confidence`、`sourceSpanSummary`、`manualFillRequired`。
- 可自动确认低风险明确事实字段，但分类、版权期、关键热度解释、对标和预测输入判断必须保留人工确认。
- 不提交原文，不提交材料原文件，不保存 raw material。
