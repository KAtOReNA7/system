# M1 应用最小后端骨架说明 v0.1

状态：已建立最小后端骨架；允许进入空库/合成数据条件下的后续业务模块设计。仍禁止真实数据导入和正式数据迁移。

## 1. 技术栈选择

仓库此前没有 `package.json`、`tsconfig.json`、`src/`、`server/` 或既有后端框架。

本轮采用最小 Node.js 后端骨架：

- Node.js 原生 HTTP 服务；
- ESM JavaScript；
- `pg` PostgreSQL 驱动；
- Node.js 内置 `node:test` 测试框架；
- 不引入 Express、Nest 或其他复杂框架。

选择理由：当前阶段只需要健康检查、配置加载和数据库连通性边界验证，原生 HTTP 足够，避免在业务规则尚未进入应用实现前引入额外框架约束。

## 4. 环境变量

只提交 `.env.example`，不得提交 `.env`。

```text
M1_APP_ENV=local
M1_HTTP_PORT=3000
M1_DATABASE_URL=
M1_DATABASE_READONLY_URL=
M1_DATABASE_BACKGROUND_URL=
```

当前允许的 `M1_APP_ENV`：

- `local`
- `test`
- `ci`

当前拒绝：

- `staging`
- `production`

原因：staging/production 不在本轮授权范围内，正式库连接配置不得作为默认能力进入应用。

## 5. 健康检查接口

### `GET /health`

不依赖数据库。

返回示例：

```json
{
  "status": "ok",
  "service": "m1-audiobook-evaluation",
  "environment": "local"
}
```

### `GET /health/db`

依赖本地/测试数据库配置。

未配置数据库时返回非敏感降级结果：

```json
{
  "service": "m1-audiobook-evaluation",
  "status": "degraded",
  "database": {
    "connected": false,
    "reason": "database_not_configured"
  }
}
```

配置数据库后检查：

- 数据库可连接；
- 数据库时区为 UTC；
- Flyway schema version 为 `0060.290`；
- `system_state` 为 `schema_initialized`；
- 5 个正式视图可查询；
- 当前连接角色不是 `migration_owner`；
- 不读取真实业务数据行；
- 不写入任何业务表。

## 6. 数据库连接角色

| 用途 | 环境变量 | 角色 |
| --- | --- | --- |
| 普通读写接口 | `M1_DATABASE_URL` | `application_rw` |
| 只读健康/查询 | `M1_DATABASE_READONLY_URL` | `application_ro` |
| 后台/控制态检查 | `M1_DATABASE_BACKGROUND_URL` | `background_worker` |

约束：

- 应用运行不得使用 `migration_owner`；
- 普通接口不得使用 `background_worker`；
- 只读查询不得使用 `application_rw`；
- 本轮不实现后台任务写入；
- 不保存真实密码；
- 不暴露连接串、用户名、密码、主机细节。

## 7. 本地开发数据库初始化

先建立空库结构：

```powershell
tools/dev-db/init-m1-dev-db.ps1 `
  -HostName 127.0.0.1 `
  -Port <local-port> `
  -AdminUser postgres `
  -DatabaseName m1_dev
```

再执行最小连通性检查：

```powershell
tools/dev-db/check-m1-db-connectivity.ps1 `
  -HostName 127.0.0.1 `
  -Port <local-port> `
  -DatabaseName m1_dev
```

应用侧连接只允许指向本地/测试/CI 数据库，不得指向正式数据库。

## 9. 仍禁止事项

仍禁止：

- 连接正式数据库；
- 写入正式数据库；
- 导入真实账单；
- 导入数字版权台账；
- 导入运营确认 Excel；
- 导入运营确认结果；
- 导入候选 `mapping_version`；
- 自动应用候选映射；
- 修改 `db/migrations/` 下已提交 SQL；
- 修改 Flyway 历史迁移；
- 修改源账单、台账、私有确认包；
- 读取 `data/` 目录作为应用启动输入。
