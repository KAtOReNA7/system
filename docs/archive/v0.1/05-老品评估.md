# 05. 老品评估

## 5.1 评估范围

老品是已经产生实销并进入老品库的标准作品。评估面向剩余版权期，不按固定周期自动运行，由运营按需发起；失效修复场景除外。

## 5.2 输入

- 全历史月度实销；
- 近12/24个月及近期收入；
- 渠道和业务形态结构；
- 版权期限；
- 产品状态；
- 分类标签；
- 买断与冲抵；
- 外部热点或重大业务事件；
- 历史运营案例和正式规则。

最终周期和权重必须由真实账单回测确定。

## 5.3 生命周期

- 一部作品同一时间只有一种生命周期类型；
- 可因外界因素在某一时点切换类型；
- 可增加“近期回升”等状态标签；
- 生命周期在前台展示；
- 先基于全渠道判断，必要时参考渠道差异；
- 分类骨架和阈值由全量账单决定。

## 5.4 预测

输出：

- 剩余版权期基准预测；
- 乐观/悲观或区间；
- 年度预测及总额；
- 主要渠道结构说明；
- 生命周期；
- 当前评级；
- 主要风险；
- 运营建议。

多算法在早期并行回测。若只有一种方法稳定有效，则正式页面只保留有效方法，不展示无意义的实验结果。

## 5.5 评级与建议

- 评级：S/A/B/C/D/E，可S+；
- 收入基础等级可作为底层信息，但老品页面是否展示按最终详情设计；
- 资源投入等级三档；
- 主建议1条，次建议最多2条，总计最多3条；
- 建议可覆盖推广、定价、合并版本、重录、打包售卖等；
- “演播表现不佳”不作为重制主因；
- 临近到期定义为半年内。

## 5.6 业务形态

有声版权与有声成品分别展示收入构成，最终只输出一个原作级综合评级、预测和建议。过去未开发另一形态时，不主动建议开发；只针对已有形态且仍在版权期内提出建议。

## 5.7 详情页

顶部概览：评级、历史累计实销、剩余版权期预测、生命周期、最多三条建议、风险、业务形态构成。

收入区：历史月度曲线、未来预测、买断单列、业务形态切换、生命周期变化和外部事件时间轴。

基础信息与历史记录通过页签或折叠区域展示。

## 5.8 失效与重评

- 数据错误、归并变化、规则变化等由AI判断必须失效或建议重评；
- 必须失效时，旧结果前台隐藏；
- 自动发起重评并通知结果；
- 自动重评失败时保持失效并进入异常清单。

## 5.9 回测

使用历史账单固定时间点，以前段收入预测后段收入，并比较实际结果。按生命周期、分类、收入规模和算法分别验证。核心指标需综合误差金额、误差比例、区间覆盖率和业务可用性。
