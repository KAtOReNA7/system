# M2 buyout false-positive business rule questions v1

本问题包用于确认买断误判修补后的业务边界。内容为脱敏问题，不包含真实作品名、作者名、渠道名或原始账单行。

## 用户确认结论

- Q1：是。连续多月实销优先；同一渠道如果发生买断，则该渠道后续 1-3 年内不应再有实销，这是强判断标准。
- Q2：不需要人工确认字段。系统按三条账单依据自动判断：大额整数收入、同批次大量相同金额、渠道候选买断后后续一段时间无实销。
- Q3：首月明显高不是买断信号，只能说明上线前期大卖、题材、特殊类别或运营手段影响。
- Q4：不需要增加收入模式证据列；系统应准确执行 Q2 的三条判断依据。

## Q1 P0 连续多月实销是否应优先压过买断形态信号？

Codex 推荐：A

用户最终确认：A，但补充强约束为“同一渠道买断后 1-3 年内不再有实销”。

- A：是。只要存在连续多月自然实销序列，就优先判纯实销，除非有明确商业条款/合同/人工确认买断。
- B：否。账单形态中出现整额、同批次、首月大额时，仍允许系统自动判买断或买断+实销。
- C：折中。连续实销优先，但首月占比超过用户确认阈值时仍进入人工复核。

## Q2 P0 买断认定是否必须依赖明确商业条款或人工确认？

Codex 推荐：A

用户最终确认：B。无需人工确认，使用三条账单依据即可。

- A：必须。没有商业条款、合同或人工确认时，账单形态只能作为疑似买断复核提示，不能直接进入买断评级。
- B：不必须。少数月份大额/整额/同批次仍可自动认定买断。
- C：仅纯买断必须明确确认；买断+实销可由系统根据账单形态推断。

## Q3 P1 首月明显高、后续持续收入的作品应如何默认处理？

Codex 推荐：A

用户最终确认：A。首月高收入不构成买断信号。

- A：默认纯实销。首月高收入可能是上线/推广/结算节奏，不直接视为买断。
- B：默认买断+实销。首月高收入作为买断候选，后续收入作为实销尾部。
- C：默认人工复核，不给自动收入模式。

## Q4 P1 任务包是否需要增加收入模式证据列？

Codex 推荐：A

用户最终确认：B。不新增证据列。

- A：需要。增加收入模式、买断证据、是否人工确认买断、买断估计金额来源等列。
- B：不需要。任务包只保留评级和预测字段。
- C：仅在疑似买断样本中展示证据列。
