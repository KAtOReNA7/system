2. 将 610 个版权到期缺口拆成高收入优先队列、普通补齐队列和 formal waiver 候选队列。

5. 明确作品状态、音频版权状态、分类和标签的来源与人工确认口径。

## 不建议现在进入 M3 的原因

1. 货架/版权状态仍有 630 个 unknown。
2. 610 个版权到期缺口覆盖约 20.88% 聚合收入。
3. 分类、标签、作品状态、音频版权状态仍全量缺失。
4. formal evaluation / export / release / audit 尚未完成。
5. 当前 M2 仍是本地候选基线，不是正式发布审批结果。

## 推荐下一步

优先启动“版权到期 610 缺口优先级队列与补齐/豁免口径设计”，然后做货架/版权状态推断规则小修。小修原则是增加复核提示和 review bucket，不扩大自动下架判断。
