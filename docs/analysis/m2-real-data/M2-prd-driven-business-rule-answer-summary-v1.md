# M2 PRD-driven business rule answer summary v1

本文件记录用户在对话中对 Q1-Q12 的业务决策回答。内容为脱敏聚合规则，不包含真实作品名、作者名、渠道名或原始账单行。

## 关键结论

- Q1/Q2/Q3/Q7/Q8/Q9/Q10/Q12：采用选项 A。
- Q6：采用选项 B。版权台账由公司版权部负责，可信度高；版权/下架状态不需要在本层与收入互相约束，后续如发现不符再由运营调整状态。
- Q11：采用选项 C。M4 校准案例池应由运营选择经典、关键作品沉淀业务经验，不自动把前序算法错题汇入样本池。
- Q4：买断摊销默认 3 年；如剩余版权期更短，则按剩余版权期限制；最低 1 年。
- Q5：评级统一按月均实销等价值计算。

## 买断与混合收入口径

- 纯买断当前评级：使用最新买断金额除以 Q4 确认的周期月数，得到月均实销等价值后进入评级。
- 纯买断下一周期预估：如果存在上一买断周期信息，可用上一买断金额除以上一周期月份数得到月均实销参考。
- 买断+实销当前评级：买断金额在对应周期均分为月均实销，与当周期原实销月均相加后评级。
- 买断+实销下一周期预估：只预估实销部分，不预估未来买断谈判。
- 前台展示后续应能标记评级是否含买断；本轮在规则和任务包说明中记录，不进入 M3。
