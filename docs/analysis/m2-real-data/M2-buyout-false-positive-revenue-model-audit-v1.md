# M2 buyout false-positive revenue model audit v1

本报告记录用户指出的 5 个 private 任务包样本被误认为包含买断后的核查结果。报告只保留脱敏聚合结论，不包含真实作品名、作者名、渠道名或原始账单行。

## 核查结论

- 当前工作区的 `rating-standard-v4.xlsx` 未直接包含用户指出的 5 个样本。
- 这 5 个样本出现在 after-dual-source-staging 任务包来源中。
- after-staging 任务包本身没有收入模式或买断估计金额字段，因此“包含买断”的判断来自后续收入模式分类链路，而不是该 Excel 的字段本身。
- 算法根因是：渠道收入分类先判断买断/混合，再判断自然连续实销；当收入存在整额、同批次、首月较大等信号时，可能压过多月连续实销证据。

## 用户确认的买断判断规则

- 对于同一作品同一渠道，买断的强信号是：一旦该渠道发生买断，后续 1-3 年内不应再有该渠道实销。
- 买断自动识别不需要依赖人工确认字段，但必须准确执行三类账单证据：
  - 大额整数收入；
  - 同批次账单中大量相同或近似相同金额；
  - 候选买断月后该渠道后续观察窗口无实销。
- 首月明显高、后续仍持续收入不是买断信号，只能说明该作品存在上线前期大卖、题材、特殊类别或运营手段影响。
- 任务包不新增收入模式证据列，系统应直接按上述三条判断依据准确执行。

## 已做最小修正

- JS 领域规则与 Python 真实数据生成脚本均加入“候选买断月后无实销观察窗口”特征。
- 候选买断月后至少 12 个观察月无正收入，才形成强买断后无实销信号。
- 同一渠道只因首月大额或首月高占比，不再判买断或买断+实销。
- 同一渠道大额收入后仍有持续实销时，按上线前期大卖或自然实销序列处理。
- 买断+实销保留为作品级聚合：不同渠道/阶段中同时存在买断渠道和实销渠道时成立。
