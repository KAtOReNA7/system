# M2 v1.1 Business Review User Guide

Candidate version: `m2-realdata-dev-disentangled-forecast-v1.1-conditional`.

The review purpose is to decide whether the conditional v1.1 forecast baseline is acceptable for limited M2 business review on forecastable cohorts only. It is not final release approval and does not open M3 by default.

## Workbook Sheets

| Sheet | Use |
|---|---|
| 00_read_me | read the candidate boundary, non-release status, cohort definitions, and business decision task |
| 01_executive_summary | check WAPE, baseline comparison, coverage, P0/P1/P2, applicable scope, and remaining restrictions |
| 02_forecastable_cohort_review | review anonymous forecastable rows and decide whether forecast confidence/action labels are acceptable |
| 03_high_value_review | inspect high-value anonymous cases because top revenue coverage remains weaker than overall coverage |
| 04_non_forecastable_cohort | confirm that blocked or observe-only rows do not receive business-usable numeric forecasts |
| 05_formal_readiness_blocked_but_forecastable | separate local forecast validation from formal release blockers |
| 06_business_action_guard | confirm action-bearing suggestions still require manual business review before execution |
| 07_warning_and_p2_cases | review warning/P2 cases before accepting the conditional baseline |
| 08_user_decision_template | record group-level accept/reject/pending decisions, reviewer reason, reviewer name, and date |

## Decision Options

| Decision Option |
|---|
| accept_limited_business_review_baseline |
| accept_with_manual_high_value_review |
| reject_for_algorithm_rework |
| keep_pending |

## Restrictions

| Restriction |
|---|
| do not use this as final release approval |
| do not use non-forecastable rows for numeric business decisions |
| do not enter M3 unless the user explicitly authorizes parallel planning after accepting the baseline |
| do not commit the private workbook |

This guide is sanitized and aggregate-only.
