# M3-3.5 external evidence implementation plan v0.1

Generated: 2026-06-28

## Goal

Add a structured external evidence and research-assist layer to M3 fixture/prototype evaluation.

## Implementation

- Add external evidence domain module.
- Add research question generator.
- Add synthetic external evidence fixture data.
- Apply confirmed evidence to readiness-derived fields.
- Feed evidence into forecast weighting contribution explanations.
- Feed evidence into rating explanation.
- Extend fixture repository and API with external-evidence and research-question endpoints.
- Extend read-only admin prototype.
- Add automated tests.

## Explicit Non-goals

- no real search;
- no ChatGPT web call;
- no Chrome plugin call;
- no browser automation;
- no database connection;
- no migration;
- no private material read;
- no webpage full text storage;
- no development recommendation;
- no resource investment level;
- no forecast range;
- no formal execution.

## Manual Research Policy

Users can use GPT web, Chrome or other tools manually outside the current system. Results must be entered as structured evidence with source, query, timestamp, confidence and manual confirmation.
