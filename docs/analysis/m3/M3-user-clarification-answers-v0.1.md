## 后续开发约束

- M3-1 默认入口必须是 Word/PDF/PPT/物料表/物料文本 fixture。
- 标准化选题表只能作为 fallback。
- 预测输出必须是 point estimate，不输出 high/base/low、optimistic/pessimistic 或 forecast range。
- `channelForecasts[]` 必须可相加得到 `totalForecast`。
- M2 老品评估后续需要记录“弱化或删除预测区间”的 follow-up，但本轮不修改 M2。

## 安全确认

- 本文件不包含真实作品名、作者名、渠道名、原始账单行、原始台账行、完整作品明细或真实物料内容。
- 本文件不提交 private Excel、CSV、JSON、Word、PDF、PPT 或原始材料。
