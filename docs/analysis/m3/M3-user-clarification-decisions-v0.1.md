# M3 用户澄清决策记录 v0.1

生成日期：2026-06-28

状态：M3-0 用户答复已记录。本文件只固化需求决策，不进入 M3 formal execution，不实现业务代码，不读取或提交 private 物料。

## 决策摘要

M3 的入口应从“选题物料解析”开始，而不是从标准化选题表开始。结构化选题表只作为少数缺少完整物料的小众选题补充入口。M3 可以启动本地非正式候选开发，但不得进入 formal execution、正式发布、正式 task/export/write API 或自动替代人工选题决策。

## 对 M3 PRD 的修正

- M3-1 输入主路径：private 选题物料。
- M3-1 补充路径：结构化选题表，仅用于少数没有完整物料的选题。
- 核心阻断字段：身份、分类、热度、版权期。
- `source` 枚举：出版物、原创网文。
- 预测输出：渠道级点值预测、总和点值预测、五年累计、首年、1-5 年拆分。
- 取消预测区间作为主输出。
- M2 后续也需要评估是否从区间预测转向高概率命中点值预测。
- 分类候选不能自动确认。
- 物料解析可自动确认低风险明确字段，但必须保留来源证据和人工复核边界。

## 仍然禁止

- 不进入 M3 formal execution。
- 不输出“是否建议开发”。
- 不输出资源投入等级。
- 不提交 private 选题物料、Word、PDF、PPT、Excel、CSV、JSON。
- 不提交真实作品名、作者名、渠道名、原始账单行、原始台账行或完整作品明细。
- 不写正式 task/export/write API。
- 不连接远端生产、共享、staging-like 或未授权数据库。

## 下一步

进入 M3-1 设计时，应优先围绕“物料解析 -> 字段候选/自动确认边界 -> 核心 readiness -> 渠道级点值预测输入需求”建立最小闭环。
