作品发生—金额校准模型 v0.3（M2-WORK-OA03）继续只是兼容性现行运行回退；人工锚定可学习全局模型（M2-WORK-LG01）继续是 Core 老品金额实验的主要研究比较基线。核心老品分周期金额模型 v0.1（M2-WORK-CHAM01）的既有性能与数值稳定性失败、LG01 头部现金残差校准模型 v0.1（M2-WORK-HCRC01）的失败结果均保持冻结。LG01 头部保护分段路由模型 v0.1（M2-WORK-HPSR01）的原 v0.1 合同结果继续是回溯开发不支持，科学解释状态为 M2_HPSR01_CONTRACT_UNSUPPORTED_SCIENTIFICALLY_INCONCLUSIVE，两者均保持冻结。LG01 头部保护尾段修正模型 v0.2（M2-WORK-HPSR02）已完成唯一一次 2026-03 起点独立评价：动态 Core80 为 43 部，候选 WAPE 为 64.1150%，相对冻结 LG01 同案例基线的 relative FVA 为 0.5179%，2,000 次作品 cluster bootstrap 95% 区间为 [-2.4406%, 3.8718%]，未达到 1% 支持门限且区间跨 0，最终为证据不足并结束现金-only 相邻研究（M2_HPSR02_FIRST_INDEPENDENT_INCONCLUSIVE_CASH_ONLY_RESEARCH_ENDED）。positive base floor、q05 与 q95 继续是不可变冻结模型参数（IMMUTABLE_FROZEN_MODEL_PARAMETER）；旧 577 行仅为参数谱系快照（PARAMETER_LINEAGE_SNAPSHOT）。当前账单形成 2026-03 输入与 2026-04 至 2026-06 作品总额 actual；渠道行级两侧各 732 行漂移继续登记且不改写参数或 actual。七次结果前工程停止、两个历史阻断检查点和冻结结果均保留。作品—渠道门禁继续为部分且未激活；前瞻最终留出、第二独立起点、后继现金模型、活动候选、自动化与生产权限均为空。出版行业渠道起点可见现金锚金额设计 v0.1（M2-PREREG-PSC02-ORIGIN-VISIBLE-CASH-ANCHOR-01）只完成数学预注册与公共合成 reference 验证，没有创建模型 ID、真实实现、拟合、预测或评价；活动候选、自动化、production 与 final holdout 继续为空。
