# OA03 最近 12 个完整账单月已有成熟渠道分配报告 v0.1

本报告评价父实验
`M2-EXP-OA03-CURRENT-SCOPE-REPLICATION-01`
中的“作品总额 × 最近 12 个完整账单月已有成熟渠道份额分配臂”
（对象类型：observed-channel allocation capability）。

最终结论为：

- 3 个月：混合（`OA03_TRAILING12_CHANNEL_ALLOCATION_MIXED`）；
- 6 个月：不支持（`OA03_TRAILING12_CHANNEL_ALLOCATION_NOT_SUPPORTED`）；
- 12 个月：混合（`OA03_TRAILING12_CHANNEL_ALLOCATION_MIXED`）。

因此不能确认一个跨 3/6/12 月统一稳定的渠道分配能力，也不能用该结果改变
作品发生—金额校准模型 v0.3
（Occurrence-Amount Calibration v0.3，`M2-WORK-OA03`）的作品总额角色。

## 冻结分配合同

- 作品总额来自同 origin、同 horizon 的 `M2-WORK-OA03` 复现结果。
- 份额只读取 origin 前最近 12 个完整账单月的非负收入。
- 只分配到 origin 时已经出现并至少成熟 3 个完整账单月的 canonical 渠道。
- 未来首次渠道和起点未成熟渠道保持 `null abstain`。
- 零分母只允许在最近 12 个月内回退到最近一个非零月份；仍无依据则弃权。
- 不允许等分，不允许读取未来 actual 渠道份额。
- 分币使用 BigInt 和稳定渠道 ID tie-break 的最大余数法。
- 没有比较 trailing-3 或 trailing-6，也没有根据结果更换窗口。

## 守恒、成功与弃权

- 共尝试并成功完成 7,025 个作品总额分配。
- 生成 36,484 条成熟渠道预测行。
- 作品级合法弃权为 0；所有成功分配的渠道预测之和与作品总额逐分相等。
- 最大守恒差为 0 分。
- 另有 7,286 个渠道级合法 `null abstain`：
  - 未来首次出现渠道 5,543；
  - 起点未成熟渠道 1,743。
- 这些弃权没有被记作 0 预测，也没有被计作守恒失败。

## 匿名主要渠道误差集中

为保护 private identity，公开结果只使用
`MAJOR_CANONICAL_CHANNEL_001` 等匿名排名，不发布渠道名或渠道 ID。

- Core80 Primary 的第一匿名主要渠道贡献约 66.43%–69.45% 的绝对误差；
- Core80 Strict 的第一匿名主要渠道贡献约 59.98%–63.23%；
- 第二匿名主要渠道约贡献 10.81%–14.02%；
- 小于隐私阈值的切片保持指标抑制。

误差集中说明分配误差受头部渠道显著影响，是“混合/不支持”结论的重要限制；
它不授权针对已看到的渠道结果改窗口或调倍率。
