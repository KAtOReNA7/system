# M2 分层收入四分量守恒审计 v0.1

对象：分层收入组合模型 v0.1（`M2-PORT-LRC01`）
实验：分层收入组合实验（`M2-EXP-LAYERED-REVENUE-COMPOSITION-01`）
结论：守恒通过，预测质量失败。

## 规则

每一条未来分成现金只能进入一个分量，优先级固定为：

1. 未来新增作品组合；
2. 现有作品新增渠道组合；
3. 现有核心作品；
4. 现有长尾作品。

因此未来新增作品不会同时计入新增渠道。四分量使用整数 minor unit，必须满足：

`现有核心 + 现有长尾 + 未来新增作品 + 现有作品新增渠道 = 公司分成现金总额`。

## 结果

- 权威冲销重述守恒差：0。
- 70 个合法 origin × Core80/Core90 × 3/6/12/24/36 月 actual cache 的最大
  四分量守恒差：0。
- 原始冲销删除数：0。
- 主路线跨 horizon actual 占比：现有核心 45.3612%、现有长尾 7.6936%、
  未来新增作品 41.3585%、现有作品新增渠道 5.5866%；合计在浮点容差内为 100%。
- 买断与其他非分成现金没有进入分量、标签或指标。

守恒通过只证明现金分类完整且互斥，不证明预测准确。12/36 个月主结果仍失败，
不能用守恒状态掩盖误差。
