最终执行状态为“私有执行在形成预测前失效，且一次基础设施重试已经耗尽”

## 实际执行了什么

在公共实现、测试以及精确提交 Linux/Windows CI 通过后，正式私有执行启动。首次尝试
在合法样本物化阶段遇到特征回调变量接线错误；没有开始模型训练，也没有形成预测。
失败收据按合同保留。

只修复该基础设施接线并重新通过完整公共门禁和精确提交双平台 CI 后，执行了合同允许
的唯一一次基础设施重试。重试在作品发生—金额校准模型 v0.3 当前范围重建阶段发现：
共享 Python 物化器只允许原 OA03 能力目录，而新实验正确地使用自己的能力隔离目录。
失败仍发生在模型训练和任何预测之前。

合同只允许一次基础设施重试。尽管没有形成预测，也不得进行第三次执行。因此：

- 作品发生—金额校准模型 v0.3 与人工锚定可学习全局模型的同案例误差归因未生成；
- 冻结研究基线臂及三个候选臂均没有形成可评价输出；
- 3、6、12 个月均为“未评价”，不能写成通过、部分通过或失败；
- WAPE、signed bias、MAE、median AE、FVA、2,000 次作品聚类 bootstrap、
  时间块胜率和最佳原始实验臂均保持 `null`；
- Core90 方向未知，不能声称一致或退化。

## 修复与硬边界

共享物化器现以显式 capability ID 在两个固定允许目录中工作；原 OA03 能力目录边界
没有放宽到任意目录。同时增加了恢复机会只能消费一次的硬防护。上述修复没有改变模型
结构、特征、参数网格、fold、训练权重或评价门。

修复后仅执行公共 synthetic 验证和仓库公共门禁，没有再次读取私有源或训练模型。
未来若要再次执行，必须由用户在新的任务中明确授权，并绑定新的精确提交
Linux/Windows CI。
