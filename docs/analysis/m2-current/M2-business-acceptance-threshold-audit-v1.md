## 1. 结论

本轮完成的是一次业务规模与验收阈值审计，不是模型开发、训练、调参、选择或
独立后期评价。

本报告首次出现时采用以下全称，后文括号内简称只用于阅读：

- 人工锚定可学习全局模型（Human-Anchored Learned Global，
  `M2-WORK-LG01`；简称 LG01）；
- 作品发生—金额校准模型 v0.3（Occurrence-Amount Calibration v0.3，
  `M2-WORK-OA03`；简称 OA03）；
- 核心收入人工规则基线 v0.1（Core-Revenue Manual Rule Baseline v0.1，
  `M2-WORK-CRMR01`；简称 CRMR01）；
- LG01 头部保护分段路由模型 v0.1（LG01 Head-Protected Segmented Router
  Model v0.1，`M2-WORK-HPSR01`，所属实验
  `M2-EXP-LG01-HEAD-PROTECTED-SEGMENTED-ROUTER-01`；简称 HPSR01）；
- LG01 头部保护尾段修正模型 v0.2（LG01 Head-Protected Tail-Band
  Correction Model v0.2，`M2-WORK-HPSR02`，同属上述实验；简称 HPSR02）。

直接回答本轮七个业务问题：

- **账单规模和集中度**：69 个完整历史起点中，Core80/Core90 每起点平均约
  20.55/39.88 部；Core80 四周期累计 current actual 从 ¥73.79 百万至
  ¥687.11 百万，Top10 吸收约 75.5%–78.7% 的人口内 actual，现金高度集中。
- **历史误差可达范围**：合法 LG01 冻结证据的总体 WAPE 在 H3/H6/H12/H36 的
  Core80 为 25.16%/26.73%/30.56%/29.73%，Core90 为
  27.39%/28.75%/32.81%/34.14%；当前范围 OA03 和 CRMR01 多数更差。
- **初始门限严宽**：H3/H6 的 30%/32% WAPE 初始线并不过严；H12 的 32% 对
  Core90 略紧，适合做 32%–35% 敏感区间；H36 的 35% 总体线可用，但逐起点
  只有 6/13 同时通过 WAPE/偏差，不能单凭总体成绩激活。
- **建议区间**：H3/H6 建议 WAPE 30%–32%，H12 建议 32%–35%，H36 建议
  35%–40%；绝对偏差均建议 10%–12%，全部等待用户批准。
- **人民币金额**：Core80 每起点 actual 中位数约为 H3 ¥0.60 百万、H6
  ¥0.94 百万、H12 ¥1.63 百万、H36 ¥3.54 百万；冻结同案点领先的误差减少从
  H3 的 ¥12,121.54 到 H36 的 ¥4,944.66 百万不等，必须结合健康基线解释。
- **36/60 个月**：H36 用 13 个合法历史起点作当前硬门禁并标注未 prospective
  验证；H60 只预留为未来 M3 precursor 的低置信成熟目录情景，不进入当前 M2
  排名、门禁或实现。
- **不能只用 1% relative FVA**：relative FVA 的分母是基线误差，基线失控时会
  夸大改善，基线误差很小时又可能对应很少人民币；新模型必须同时达到 actual
  现金 materiality、人民币误差减少、bootstrap/时间稳定、偏差、H50 和误差集中
  保护。建议使用“actual 现金至少 1%”而不是“relative FVA 至少 1%”作为物质性
  中心线。

审计支持把以下区间提交给用户决策，但**没有激活任何门禁**：

| 硬业务输出 | WAPE 建议区间 | 绝对偏差建议区间 | 解释 |
|---|---:|---:|---|

候选优越性门槛建议继续采用“至少相当于实际现金的 1%”，或由用户另行确认一个
人民币最低金额；它必须同时报告相对预测增值、绝对误差减少人民币和实际现金

当前不能激活阈值，原因不是缺少源权威，而是：

1. 36 个月精确同案逐行缓存未保留，无法完成候选与基线之间的精确 H50 不恶化检查；
2. 全部模型证据仍是开发或回溯证据，不是独立后期证据；
3. 12 个月与 36 个月在建议阈值下的逐起点通过率仍弱于建议的三分之二稳定性要求；
4. HPSR01 只有一个非独立回溯起点，只能作为上下文，不能设定阈值。

## 9. 建议门禁结构（未激活）

业务可用性门禁与候选优越性门禁必须分开：

1. 业务可用性：
   - 总体 WAPE 在用户批准的周期区间内；
   - 总体绝对偏差在用户批准的周期区间内；
   - 逐起点人民币绝对误差与总有符号误差公开；
   - H3/H6/H12 至少两个独立起点且建议至少三分之二起点同时通过；
   - 一个独立起点可以否定明显失败，不能确认稳定成功；
   - H36 可暂用多历史起点作当前硬门禁，但必须标记未 prospective 验证。
2. 候选优越性：
   - 报告相对 FVA；
   - 绝对误差减少至少达到 actual 的 1%，或用户确认的人民币最低金额；
   - 2000 次整作品聚类 bootstrap 不支持时不能宣称稳定改善；
   - 时间块、H50、偏差和误差集中保护同时通过；
   - 不允许 L20 掩盖 H50。
