# M2 用户确认简表（中文版）v0.1

> 当前状态（2026-07-25）：A1–A6 与 B1–B4 已完成并写入
> `config/m2-current-user-confirmation.v0.1.json`。除非业务事实变化，不再要求
> 用户重复填写；本文件仅保留为空白模板和字段说明。

## 使用范围

本表只收集当前无法由仓库代码或已有权威材料自动判断的信息。用户不需要填写
算法名、内部字段名、预测金额或英文状态。

不知道的内容直接填写“**不清楚**”；没有材料时填写“**没有**”。系统不得把
“不清楚”推断成分成、买断、退款、冲销或 0 元。

## 表一：负向现金性质确认

当前只需要确认一笔金额为 **-230.38 元**的负向现金。不得在本公开表中填写作品
名称、渠道账号、合同编号或其他敏感标识。

| 编号 | 需要确认的内容 | 可选填写值 | 你的填写 |
|---|---|---|---|
| A1 | 是否有原始依据 | 有 / 没有 / 不清楚 |  |
| A2 | 这笔钱属于哪类收入 | 分成收入 / 买断收入 / 其他非分成收入 / 不清楚 |  |
| A3 | 这笔负数是什么事件 | 退款 / 冲销 / 结算调整 / 其他 / 不清楚 |  |
| A4 | 依据是什么 | 原始结算单 / 财务凭证 / 合同条款 / 财务系统记录 / 只有口头判断 / 没有 |  |
| A5 | 材料是否已提供 | 已放入本地受控目录 / 已作为附件提供 / 暂未提供 |  |
| A6 | 补充说明 | 一句话说明；没有可填“无” |  |

### 表一填写说明

1. A2 和 A3 必须来自 A4 的原始依据，不能只根据作品类型或授权分类判断。
   - “退款”表示已结算收入被退回；
   - “冲销”表示撤销一笔此前已经入账的记录；
   - “结算调整”表示结算方另行增加或扣减，但材料没有写成退款或冲销。
2. 如果 A4 只有“口头判断”或“没有”，系统继续保持“无法确认并弃权”，不会
   自动归类。
3. 原始材料放在 Git 忽略的 `data/private-input/m2-user-confirmation/`，或者直接
   作为本次任务附件提供；不得提交到 GitHub。
4. 最简回复格式：

```text
A1=有
A2=分成收入
A3=退款
A4=原始结算单
A5=已作为附件提供
A6=无
```

## 表二：历史数据源确认

这张表不是让用户整理数据，只需确认公司现有系统或文件中是否存在对应历史记录。
每一行均可填写“不清楚”。

| 编号 | 可能的数据源 | 是否存在 | 是否保留历史版本 | 能否导出 | 最早可追溯月份 | 材料或负责人 |
|---|---|---|---|---|---|---|
| B1 | 渠道分成结算明细 | 有 / 没有 / 不清楚 | 有 / 没有 / 不清楚 | 能 / 不能 / 不清楚 | 例如 2021-01；不清楚也可 | 文件、系统或负责人 |
| B2 | 退款、冲销、调账明细 | 有 / 没有 / 不清楚 | 有 / 没有 / 不清楚 | 能 / 不能 / 不清楚 |  |  |
| B3 | 作品在各渠道的可售、上架或下架历史 | 有 / 没有 / 不清楚 | 有 / 没有 / 不清楚 | 能 / 不能 / 不清楚 |  |  |
| B4 | 分成合同的生效、失效或状态变更历史 | 有 / 没有 / 不清楚 | 有 / 没有 / 不清楚 | 能 / 不能 / 不清楚 |  |  |

如果 B1 或 B2 可以导出，再确认导出文件能否提供下列信息：

| 编号 | 文件信息 | 有 / 没有 / 不清楚 |
|---|---|---|
| C1 | 每笔记录对应的作品 |  |
| C2 | 每笔记录对应的渠道 |  |
| C3 | 正常收入、退款、冲销或调账类型 |  |
| C4 | 收入实际归属的时间 |  |
| C5 | 财务正式入账的时间 |  |
| C6 | 该记录在系统中首次可以查询的时间 |  |
| C7 | 来源批次、版本号或稳定的记录编号 |  |

### 表二填写说明

1. 用户只确认“有没有”和“能不能导出”，不需要自己清洗、合并或改字段。
2. “只有当前状态、没有历史版本”应填写“没有保留历史版本”，不能当作历史数据。
3. 如果记录没有 C6，应如实填写“没有”；系统不能用文件修改时间或今天的状态
   猜测过去何时可见。
4. 可以先只回复 B1–B4；确认存在可导出的数据后，再由系统生成对应的受控导入
   模板。
5. 最简回复格式：

```text
B1=有；保留历史版本；能导出；最早 2021-01；财务系统
B2=不清楚
B3=没有历史版本
B4=有；是否能导出不清楚；运营负责
C1=有，C2=有，C3=不清楚，C4=有，C5=有，C6=没有，C7=有
```
