# M2 HPSR01 解释修订 v0.1

## 结论

LG01 头部保护分段路由模型 v0.1（LG01 Head-Protected Segmented Router
Model v0.1，稳定模型 ID `M2-WORK-HPSR01`）的原合同判定保持不变：

`M2_HPSR01_RETROSPECTIVE_DEVELOPMENT_UNSUPPORTED_STOP_BEFORE_K2`

这仍是 M2 LG01 头部保护分段路由实验
（`M2-EXP-LG01-HEAD-PROTECTED-SEGMENTED-ROUTER-01`）在 v0.1 预冻结合同下的
机械判定。新增的科学解释状态是：

`M2_HPSR01_CONTRACT_UNSUPPORTED_SCIENTIFICALLY_INCONCLUSIVE`

中文含义是：HPSR01 在原合同下被判不支持，但现有单起点证据只够说明
“尚未确认且存在偏差权衡”，不够证明整个头部保护分段方向无效。

这是解释修订（interpretation amendment），不是重新选模、重新评价或修改历史。
原回溯报告、机器 JSON、冻结预测、冻结指标和机器结果均未改写。

## 合同判定与科学解释不是同一层

| 层级 | 问题 | 结论 |
|---|---|---|
| v0.1 合同判定 | 是否按预冻结规则正确执行？ | 是。绝对偏差恶化超过 2 个百分点会独立触发不支持；实际恶化 2.0358 个百分点 |
| 科学解释 | 现有证据是否证明整个模型方向失败？ | 否。证据非独立、只有一个起点且现金带方向异质 |
| 历史治理 | 是否改写原始结果？ | 否。原状态继续保留，不改成 PASS |
| 后续授权 | 是否因此自动执行独立评价？ | 否。任何独立后期起点评价仍需数据成熟和用户另行授权 |

原合同执行没有计算错误：实际绝对偏差恶化为
`0.020358292834892863`，相对 `0.02` 硬停止线只多
`0.00035829283489286245`，即约 0.0358 个百分点。解释修订不追溯修改这条
已冻结规则。

## 为什么不能宣称“整个方向已经失败”

现有回溯证据存在以下限制：

1. 只有一个回溯预测起点 `2025-11`；
2. 只有 57 部同案例作品；
3. 头部保护分段路由实验臂 R1（H50 保留 LG01、M30/L20 修正）的 WAPE
   为 14.2019%，实际优于同实验冻结 LG01 基线实验臂 R0 的 14.3234%；
4. R1 相对 R0 的配对预测增值（paired FVA）为正，等于 0.8477%；
5. 整作品聚类 bootstrap 95% 区间为
   `[-18.3441%, +20.0303%]`，很宽且跨 0；
6. 配对 FVA 只比 1% materiality 少 0.1523 个百分点；
7. 绝对偏差只比 v0.1 的 2 个百分点硬停止线多 0.0358 个百分点；
8. 单一时间块不能验证跨时间稳定；
9. 现金带结果并非同方向：头部相等、中段变差、尾段改善。

因此，原合同的“不支持”是正确的合同输出，但不能升级解释为“整个头部保护分段
方向已被科学证明无效”。
