## 1. 结论先行

本轮完成了首个有效真实账单组合级滚动开发评价，但不能通过。3/6 个月只有绝对
误差证据，没有同案例组合比较模型；预注册主 12 个月方案 WAPE 为 0.552720、
有方向偏差为 +0.278809；36 个月方案 WAPE 为 1.963796、有方向偏差为
+0.942953。12/36 个月均明显高估，整体四 horizon WAPE 为 1.505570。

原始 runner 写出待解释状态
`M2_LAYERED_REVENUE_COMPOSITION_PARTIAL`。验证阶段只重述结论，不重跑或改写
预测：预注册主 12 个月方案比同实验诊断方案更差；36 个月辅助年龄带收缩方案与
公司目录方案逐行相同，不能声称年龄带方案已执行；Y1/Y2/Y3 也没有单独评分。因此
公开机器结论重述为失败，所有原始数值保留。

这是一项组合开发证据，不是作品点预测、训练、选模或 production 授权。现行运行
回退、研究比较基线、组合参考、活动候选和自动化授权均未改变。

## 6. 比较边界与协议缺口

- 当前 actual 定义下没有可重建的同案例公司组合比较行，因此比较状态为
  `NOT_COMPARABLE`，不计算相对 FVA，也不声称超过组合现金参考
  `M2-PORT-ETS01`。
- 分层收入组合实验的阶段 L6B（36 个月年龄带收缩辅助臂）与阶段 L6A（36 个月
  公司目录直接保留主臂）逐行相同；阶段 L6B 记为
  `NOT_EXECUTED_DUPLICATES_L6A`，其重复指标不构成第二份证据。
- 预注册的 Y1/Y2/Y3 年度分量没有单独评分；声明的私有 component rows 与
  evaluation rows 也未物化。它们是协议缺口，不用 0 或 36 月汇总值填补。
- Top revenue 后验切片未物化；没有从未来实际选择人口。
- 公开 JSON 数值均有限，分量占比合计为 1.0000000000000002（浮点容差内为 1），
  不含作品、渠道身份或本机路径。
