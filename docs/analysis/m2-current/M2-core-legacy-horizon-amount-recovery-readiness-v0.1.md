# M2 核心老品分周期金额模型恢复就绪报告 v0.1

截至 2026-07-30，核心老品分周期金额模型 v0.1（Core Legacy
Horizon-Specific Amount Model v0.1，`M2-WORK-CHAM01`）已通过正式链路
R0 合成恢复冒烟。该结论只证明恢复基础设施能够闭合，不是私有开发成绩，也不授权
生产、自动化或发布。

## 恢复边界

当前用户授权以“首个完整有效结果边界”
（`FIRST_VALID_COMPLETE_OUTCOME_BOUNDARY`）为准。首个完整私有结果形成前，
可重复修复并验证基础设施；历史合同中的固定重试次数继续作为历史审计记录保留，
但不再是本次恢复执行的阻断条件。

冻结科学合同没有变化：B0–B3、公式、特征、特征窗口、3/6/12 月、滚动
fold、参数网格、训练权重、Core80 主人口、Core90 敏感性人口、实际值定义、
人工锚定可学习全局模型（Human-Anchored Learned Global，`M2-WORK-LG01`）
比较基线、指标和门禁均保持不变。

2,000 次作品聚类 bootstrap 摘要、manifest 和 receipt 闭合路径。

也没有消耗真实科学执行窗口。

## 基础设施失败与回归覆盖

历史正式尝试中的“特征回调标识符接线错误”
（`FEATURE_CALLBACK_IDENTIFIER_WIRING`）和“能力目录策略不匹配”
（`CAPABILITY_DIRECTORY_POLICY_MISMATCH`）均已由完整正式链路回归覆盖。

R0 迭代还发现并修复了四项合成链路问题：无更早成熟训练行时错误进入内层选择、
合成 fixture 特征方差不足、公开 bootstrap 方法名被隐私守卫误判，以及 R0
自检布尔字段方向相反。它们均发生在合成恢复验证中，没有读取或选择私有结果，
也没有改变任何科学合同字段。
