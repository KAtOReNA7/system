# M2 出版行业规模适配渠道条件金额尺度根因审计 v0.1

## 结论

出版行业适配的渠道月度发生—条件金额核心（Publishing-Scale Channel Monthly
Occurrence × Conditional Amount Core，`M2-CHAN-PSC01`）的最终根因类别是：

> **估计器尺度收缩已确认，但实现正确**
>（`ESTIMATOR_SCALE_SHRINKAGE_CONFIRMED_IMPLEMENTATION_CORRECT`）。

冻结实现没有发现元/月与 horizon 总额混用、rate/amount 混用、逆变换遗漏、
Jensen/Duan 修正遗漏、发生概率重复相乘、exposure/offset 误用、clip 触发、重复行、
比较器错配或 fallback 覆盖 raw candidate。尺度塌缩在最早的起点可见经验父层
（`originVisibleEmpiricalParent`）已经出现：主评价的预测总额只占实际总额
`1.8593%`。后续全局、变现机制和重点平台层虽然逐步恢复到 `11.0718%`，仍未接近
现金尺度。

直接证据是条件金额 oracle 可移除主评价原始候选误差的 `78.1641%`，而发生 oracle
只能移除 `0.2101%`。严格滚动评价的相应数值为 `79.9934%` 和 `0.5746%`。
这不是“发生率过低”：在起点可见行上，最终发生概率质量分别是实际发生次数的
`115.2818%`（主评价）和 `115.2677%`–`131.0865%`（严格滚动各 horizon）。

证据支持另行预注册出版行业尺度适配渠道模型的下一修订设计
（`PSC02_DESIGN_PREREGISTRATION_SUPPORTED_NOT_AUTHORIZED`），但本审计没有创建、拟合、
实现或评价该修订，也没有打开 later-origin 或 final holdout。

机器可读的全部隐私安全单元格见
[`M2-publishing-scale-channel-amount-scale-root-cause-audit-v0.1.json`](./M2-publishing-scale-channel-amount-scale-root-cause-audit-v0.1.json)。

  LG01 比较器；候选拟合、候选预测生成、private evaluation 和 bootstrap 次数均为

- 没有修改 production loader、route、API、数据库、provider 或 exact v0.3。

## 从训练标签到预测的公式与调用链

| 阶段 | 公式、字段或调用 | 审计结论 |
|---|---|---|
| 月度标签 | `actualPositive`，单位为作品×渠道×未来月的分成现金金额 | 金额，不是 rate；没有 horizon 总额回填到月度行 |
| 条件金额目标 | `Math.log1p(row.actualPositive)` | 只在正金额行拟合；目标是 log 金额 |
| 金额估计 | work-balanced weighted ridge；非截距系数使用 L2 | 每部作品总权重相等，不按现金质量加权 |
| Jensen 修正 | 加权 Duan smearing：`exp(residual)` 的加权和 | 已实现，未遗漏 |
| 逆变换 | `max(0, exp(linear) * smearing - 1)` | 与冻结训练目标配对正确 |
| 数值 clip | log linear predictor 限制在 `[-30, 30]` | 冻结行没有达到 `exp(30)` 上界，不能解释低估 |
| 发生概率 | logistic/one-class probability | 合法概率范围；不是金额或 exposure |
| 两部模型合成 | `positivePoint = occurrenceProbability * conditionalPositiveAmount` | 每层及 final 只乘一次；`3,318,819` 行全部守恒 |
| horizon 合计 | 每个月度 `positivePoint` 对其 `includedHorizons` 各累加一次 | 没有月额/总额重复换算，也没有重复行 |
| 层级收缩 | occurrence 在 logit 尺度、amount 在 log1p 尺度连续混合父子层 | 条件金额平均收缩权重仅 `0.1433`，最大 `0.6960` |
| exposure/offset | 无对应拟合或预测路径 | 未发现错误 offset 或重复 exposure |
| sparse fallback | 数值失败时退到最近合格父层；未来首次渠道预测为 `0` | 会放大低尺度，但不覆盖 raw candidate |
| taxonomy | `REPORT_ONLY`，参数未估计，`taxonomyFeatureUsed=false` | 不是 prior，也不是直接金额修正；本模型中完全未参与计算 |
| 冲销口径 | `M2-ACTUAL-DEVELOPMENT-MODELABLE-RESTATEMENT-01` | candidate 与 comparator 使用同一 actual definition |

调用链为：开发可建模重述
（`applyM2DevelopmentModelableRestatementToPackedRows`）→ 月度展开
（`expandM2ChannelGenerativePackedRows`）→ 主评价交叉拟合/严格滚动拟合 →
`fitM2PublishingScaleChannelCore` → `predictM2PublishingScaleChannelMonthly` →
`scoreM2ChannelGenerativeG1Predictions`。冻结 LG01 比较器只在 raw candidate 冻结后解析。

## 根因定位与后续边界

根因可定位到以下组合，而不是模糊的“数据不足”：

1. 起点可见经验父层以每部作品等权的 `log1p` 正金额几何中心作为金额基准；它与
   现金加权的 WAPE/总额目标存在明确尺度错位，塌缩在任何 learned hierarchy 之前
   已经形成。
2. 条件金额 ridge 在同一 log 目标上拟合，transactional 节点还使用更强 L2；这会
   压缩极端高现金尾部对系数的影响。Duan smearing 已正确实现，但不足以把目标转换为
   现金质量对齐的算术总额估计器。
3. 条件金额父子混合继续在 `log1p` 尺度完成，而冻结行平均 amount shrinkage 权重仅
   `0.1433`；大多数子层仍紧贴已经过低的父层。
4. sparse pooled parent 把 final 比例进一步压到 `0.69%`–`2.95%`，是放大器；
   `SHRUNK_FIT` 仍只有 `12.69%`–`18.86%`，所以它不是首要或唯一根因。
5. occurrence、taxonomy、单位、逆变换、offset、clip、冲销口径、重复行和比较器均有
   反证，不能解释主要低估。

因此，可以在下一项独立授权中设计新的、现金尺度对齐且 origin-safe 的条件金额
估计器，并保留 raw candidate、同案例比较器和独立渠道构成诊断。该证据只支持
“另行预注册设计”，不授权新模型 ID、实现、训练、调参、private evaluation、
later-origin、final holdout、production、automation 或 release。
