# M2 出版行业真实规模与权威人口审计 v1

## 结论

K7A 已完成，未训练、选择或执行任何新模型，也没有读取新候选的外层评价结果。

历史渠道时间生成实验的机制层 `50` 部作品、平台与三级分类层 `100` 部作品门槛，
是 outcome 前合规冻结的通用治理假设，不是从本出版社真实人口、有效样本量、
集中度或训练侧学习曲线估计出的行业尺度。它们继续约束历史版本和历史 artifact，
但不能直接成为向前版本的唯一拟合资格规则。

本地权威可以证明：

- 当前 formal foundation 有 `3,053` 个标准作品实体；
- 分成账单权威有 `190,663` 行、`2,718` 个有现金历史的标准作品和 `9,053`
  个已观察作品—渠道现金关系；
- 当前没有注册的 ISBN/SKU—作品—版本关系权威，也没有独立版本实体权威；
- 已观察现金关系不等于授权关系；当前没有带起止时间、`effectiveAt`、
  `availableAt` 和版本的作品—平台授权关系表；
- 三级分类覆盖完整，但只有当前单值，不能表达多重分类，也没有历史
  `effectiveAt/availableAt`，所以只能用于当前描述性报告，不能作为严格
  forecast-origin 特征。

因此 K7B 可以继续设计训练侧支持合同，但必须把分类和授权缺口显式隔离，不能通过
当前状态或现金观察关系进行事后回填。

## 实体口径

| 对象类型 | 可审计数量 | 当前权威解释 |
| --- | ---: | --- |
| 书号/SKU | 不可得 | 没有注册的 ISBN/SKU 对应权威 |
| 版本/版次 | 不可得 | 没有注册的版本实体表 |
| 标准作品 | 3,053 | formal foundation 当前一行一作品 |
| 独立创意作品 | 不可得 | 当前没有与标准作品分离的实体 |
| 精确作者身份单元格 | 2,304 | 未解析为稳定自然人实体 |
| 分成账单行 | 190,663 | 账单事实，不是独立作品 |
| 已观察作品—渠道现金关系 | 9,053 | 不是授权关系 |
| primary / strict packed case | 58,986 / 102,743 | 预测 case，不是 SKU 或上新数量 |

任何按月行数、case 数或账单行数解释“出版社作品规模”的说法都不成立。当前唯一
可用于作品人口的稳定实体是标准作品；SKU、版本和真实出版批次需要补充独立权威后
才能审计。

## 分成现金人口与历史长度

完整分成账单窗口为 `2017-06` 至 `2026-05`，共 `190,663` 行、`2,718`
个标准作品、`39` 个规范渠道和 `9,053` 个作品—渠道现金范围。作品现金历史长度
中位数为 `32` 个月，作品—渠道历史长度中位数为 `21` 个月。

`2021-01` 至 `2025-12` 模型窗口有 `167,972` 行、`2,682` 个作品、`37`
个规范渠道和 `8,880` 个作品—渠道范围。该窗口包含 `106` 行负向冲销；它们必须
继续由 v2.2 冲销重述合同处理，不能删除或改写成零。

首次观察到正现金的年度作品数只是现金进入观察窗口的指标，不是发行、上架或首次
出版日期。尤其是窗口起点的左删失会把更早作品集中到首个可见年度，因此禁止将这些
计数解释为年度新品 SKU。

完整窗口发现 `1,761` 个逐字段完全相同的账单行。没有发票号或结算行标识时，这一
事实只能标记为“需要核验”，不能自动判定为重复错误或擅自去重。

## 三级分类支持分布

当前分类权威有 2 个一级、9 个二级和 64 个三级节点，当前覆盖率均为 100%，没有
发现冲突父节点。但 primary 的 320 个“三级节点 × outer fold”组合中，独立训练
作品数中位数只有 `5`：

- `44.38%` 少于 5 部，`68.44%` 少于 10 部；
- `83.44%` 少于 25 部；
- `93.44%` 少于 50 部，`97.81%` 少于 100 部。

strict 的 704 个“三级节点 × origin”组合中，中位数为 `9`；`85.37%` 少于
50 部，`92.90%` 少于 100 部。

这说明固定 `50/100` 的二元门会把绝大多数真实分类节点直接抹去；但也不意味着应
无条件直接拟合。向前合同应根据作品聚类有效样本量、集中度、origin 覆盖、参数规模、
学习曲线和稳定性，把节点分成直接拟合、收缩拟合、父层池化和仅报告四类。

## 单购机制的 25–32 部诊断

历史执行报告里的 `25–32` 部不是出版社年度 SKU 数，也不是单购机制的完整人口。
人口逐级收缩为：

1. `2021–2025` 分成账单窗口：71 个单购标准作品；
2. primary packed 可建模人口：48 个；
3. primary 第 0 个 outer fold 的训练集：38 个；
4. 再经过 inner fold 后，历史 v0.2 实际可建模训练范围：25–32 个。

对应历史实际训练行范围为 `8,640–11,916`，正月份范围为
`1,087–1,710`。主要原因是模型 case eligibility、外层作品分组和内层作品分组
的连续收缩，而不是完整业务规模只有 25–32 部。授权与历史时点权威缺口仍是独立
风险，但不是这个数字的主要生成原因。

## 数据质量与使用边界

- formal foundation 没有重复标准作品 ID；
- 分成账单没有无法关联到 foundation 的作品；
- 当前渠道映射覆盖 100%，映射连接没有行膨胀；
- 渠道主表的 133 个原始渠道对归并为 74 个规范渠道，但历史有效月份覆盖为 0；
- 分类与授权都缺少严格 as-of 历史，因此不得作为 strict origin 特征；
- 月度行、账单行和预测 case 都不是独立作品样本。

公开机器 artifact 只包含上述聚合，不包含作品身份、分类值、私有路径、私有 artifact
摘要或行级金额。私有逐作品 profile 仅保存在 Git ignored 的 capability 目录中。

## K7A 门禁结论

K7A 通过的含义是“真实人口和权威缺口已查清，可进入训练侧合同设计”，不是“模型已
实现、已验证、已授权或可发布”。

K7B 在读取任何新 outer outcome 前必须完成：

- 新版本 support tier 合同和 PRD amendment；
- 作品聚类的 training-side learning curve、有效样本量、集中度、系数稳定性和
  leave-one-work-out 规则；
- 算法参数只在 training side 校准；
- 分类和授权缺口的 `REPORT_ONLY`/禁用边界；
- 新模型修订、实验和实验臂的独立稳定 ID，不能覆盖历史渠道时间生成实验。

`M2-publishing-scale-threshold-and-assumption-lineage-v1.json`；本报告的完整公开
聚合见同名 JSON。当前阶段没有打开 private 模型执行、later-origin、final holdout、
release 或 M3 formal 能力。
