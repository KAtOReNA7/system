## 原冻结 OA03 重合验证

语义重放诊断找到当前 10,350 个 Primary 评价案例、原冻结 6,412 个案例和
5,792 个 case-key 交集。公式版本相同，但：

- actual 定义不同；
- 训练支持合同不同；
- 当前 v2.2 actual 没有为匹配历史数字而回写。

因此状态为 `NOT_COMPARABLE_DIFFERENT_CONTRACT`，逐行预测相等率、最大差、总和差、
WAPE 差和 bias 差均不应计算。该状态是合同不可比，不是技术复现失败。
