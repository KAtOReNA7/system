## 可以直接冻结的字段语义

- 当前账单表头为七个已冻结业务字段，实销金额是唯一金额字段。
- 正式收入事实必须保留原始渠道 ID、原始渠道名称、授权分类、原始作品 ID 和作品名称，并使用文本语义保存 ID。
- 金额必须使用 Excel 底层完整精度和精确十进制语义；候选物理类型为 `NUMERIC(32,18)` / `DECIMAL(32,18)`，最终在物理模型阶段确认。
- 原始事实与渠道/作品映射投影必须分离，所有候选映射均不能自动启用。
