# 文件指纹和业务内容重复报告

## 已确认的数据事实

- 文件 SHA-256 重复组 0 个；忽略行顺序后的业务内容重复组 0 个。
- 文件名未作为重复判断依据。

## 候选规则（未启用）

- 二进制指纹用于普通上传阻断；业务内容指纹只作为风险提示，不能替代正式规则。

## 无法单靠账单确认的事项

- 当前只有一个文件，无法验证跨文件重复、格式变化但内容相同等情况。

## 需要运营确认的样本

- 无须公开原始文件名或内容。

## REQ 与 AT

REQ-DATA-IMPORT-002、REQ-DATA-IMPORT-007；AT-M1-002、AT-M1-007

## PENDING-DATA 状态

跨文件内容重复规则仍为 PENDING-DATA。
