# RB-WORK-LAUNCH-001 首次实销金额符号验证

## 已确认的数据事实

- 可计算 3,099 个标准作品的最早账单月份。
- 其中 12 个作品的最早月份包含零值或负值记录，9 个作品的最早月份合计不大于零。

## 已确认规则

- 标准作品和业务形态的首次实销月份，均取首次出现正数实销记录的月份。
- 零金额和负金额不作为首次实销。
- 同月存在正数和负数时，只要存在正数记录，该月可以作为首次实销月份。
- 从未出现正数实销的作品，首次实销月份留空并进入异常确认。
