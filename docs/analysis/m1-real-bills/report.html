范围、数据与指标定义

范围为 data/real-bills/ 下全部 XLSX/XLSM 文件。数据行为七字段表头之后的非空行；总实销为所有可精确解析实销金额之和，包含零值和负值；重复只表示候选，不代表已确认删除。

方法保证原始账单只读且结论可复现

脚本使用只读工作簿模式逐行解析，运行前后校验 SHA-256、大小和修改时间。公开报告只写聚合统计和匿名样本编号；原始确认样本写入被 Git 忽略的本地目录。所有候选规则保持禁用。

单一账单文件无法完成主数据和阈值冻结

  • 七字段不含作者、完整分类、版权期限和标签。
  • 一个文件无法覆盖跨文件重复和模板漂移。
  • 渠道多重关系、重复、冲抵、分册和产品状态均需要运营确认。
  • 单机耗时是容量基线，不是生产 SLA。

先完成运营确认和补充数据，再冻结物理模型

  1. 按本地私有样本完成渠道、作品名称/授权分类、重复和分册确认。
  2. 确认 RB-WORK-LAUNCH-001 的零/负金额规则。
  3. 提供作者、分类、版权期限和标签的权威补充来源。
  4. 确认后更新 REQ/AT 或 ADR，再决定物理字段、索引和分区。

仍需回答的业务问题

  • 确认当前不同渠道 ID/名称组合中是否存在同一主体的历史更名或别名。
  • 确认同一作品 ID 多名称、多授权分类的业务解释。
  • 确认正负金额候选是否为合法冲抵。
  • 确认同名多 ID 和分册标记候选是否属于历史分册归并。
  • 确认零金额或负金额能否决定首次实销月份。
  • 确认金额隐藏精度是有效业务精度还是历史计算尾差。
  • 确认最新月份 2026-05 是否为完整结算月份。
  • 提供作者、完整分类、版权期限和标签的权威补全来源。
