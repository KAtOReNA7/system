# 金额精度、零值和负值报告

## 已确认的数据事实

- 基于 XLSX 内部 XML 原始数值文本计算的总实销为 253,610,173.052；正数 192,233 行、零值 485 行、负数 158 行、无法精确解析 23 行。
- 当前观察到的原始数值最大小数位为 18，最大整数位数为 9；133,174 行的原始小数位超过 Excel 显示格式。
- 金额列公式单元格为 0；科学计数法文本按 Decimal 原样解析，不做浮点转换。

## 候选规则（未启用）

- 已确认金额权威语义：使用 Excel 底层完整精度和精确十进制计算，不按 Excel 显示位数舍入入库，不允许使用 `float` / `double` 作为金额权威存储或对账计算。
- 物理类型候选为 `NUMERIC(32,18)` / `DECIMAL(32,18)`，最终在物理模型阶段结合目标数据库确认。

## 无法单靠账单确认的事项

- 负数和零值的具体业务原因不能单靠金额符号确认；不得自动删除。
- Excel 显示精度不能证明应当对原始存储值执行舍入。

## 需要运营确认的样本

- 负数、零值代表样本位于本地 `representative-acceptance-rows.csv`；隐藏精度和科学计数法样本位于 `amount-precision-review.csv`。
