# M1 运营确认包 v2.2 聚合摘要

## 修订范围

v2.2 仅修正“确认进度总览”中“非阻断观察”的进度与完成率公式，保留 v2.1 和所有任务明细。

## 公式语义

- `已确认`、`待确认`、`需补充资料`互斥，三者合计等于任务总数；
- `未解除阻断`只统计“是否升级为阻断=是”且解除状态不是“已解除”的记录；
- `未解除阻断`是独立风险指标，不进入任务总数或完成率分母；
- 完成率为 `已确认 / 任务总数`；
- 空值归入待确认，不视为人工确认结果。

当前 90 条非阻断观察的三个运营填写字段均为空，因此聚合结果为：已确认 0、待确认 90、需补充资料 0、未解除阻断 0、完成率 0%。
