## 已解除的 PENDING-DATA

以下事项已基于真实账单分析和运营/财务确认解除待定：

1. **完整数据截止月份**
   - `2026-05` 确认为不完整账单月份。
   - 当前最新已确认完整月份为 `2026-04`。
   - 系统必须区分“账单最大月份”和“最新已确认完整月份”。
   - 不完整月份的收入事实继续保存，但不得作为正式评估的数据截止月份。
   - 对应：`REQ-DATA-IMPORT-006`、`AT-M1-006`。

2. **首次实销月份金额符号**
   - 标准作品和业务形态的首次实销月份，均取首次出现正数实销记录的月份。
   - 零金额和负金额不作为首次实销。
   - 同月存在正数和负数时，只要存在正数记录，该月可以作为首次实销月份。
   - 从未出现正数实销的作品，首次实销月份留空并进入异常确认。
   - `RB-WORK-LAUNCH-001` 已确认。
   - 对应：`REQ-WORK-003`、`REQ-WORK-004`、`AT-M1-022`、`AT-M1-023`。

3. **金额精度语义**
   - 财务认可 Excel 底层完整精度。
   - 实销金额必须使用精确十进制语义保存和计算。
   - 不按 Excel 显示位数舍入入库。
   - 不允许使用 `float` / `double` 作为金额权威存储或对账计算。
   - 全量账单统计：最大整数位为 9，最大小数位为 18，当前最大批次合计为 `253610173.052208979970873801`。
   - 物理类型候选为 `NUMERIC(32,18)` / `DECIMAL(32,18)`，最终仍在物理模型阶段确认。
   - 对应：`REQ-DATA-IMPORT-001`、`REQ-DATA-IMPORT-004`、`AT-M1-001`、`AT-M1-004`。

4. **版权开始日期字段语义**
   - 运营确认数字版权台账中的 `签订日期` 即授权或版权生效日期。
   - `签订日期` 作为标准作品的版权开始日期。
   - `到期时间` 作为标准作品的版权到期日期。
   - 两种业务形态继续共享标准作品层版权期限。
   - 同一标准作品出现多组不同 `签订日期` 或 `到期时间` 时，不自动选择，进入版权期限冲突确认。
   - 台账未覆盖或日期缺失的标准作品继续进入基础信息补全。
   - 版权开始日期不得根据作品上线时间、首次实销月份或文件创建时间推算。
   - 对应：`REQ-WORK-008`、`REQ-WORK-009`、`REQ-WORK-011`、`AT-M1-027`、`AT-M1-028`、`AT-M1-031`。
