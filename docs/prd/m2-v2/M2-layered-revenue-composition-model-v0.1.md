# M2 分层收入组合模型 v0.1

英文名称：Layered Revenue Composition Model v0.1  
稳定模型 ID：`M2-PORT-LRC01`  
实验 ID：`M2-EXP-LAYERED-REVENUE-COMPOSITION-01`

## 目标

预测未来 `billMonth` 的分成收入，并把每个预测起点与 horizon 的公司实际现金严格
拆为四个互斥部分：

1. 现有核心作品收入；
2. 现有长尾作品组合收入；
3. 未来新增作品组合收入；
4. 现有作品新增渠道组合收入。

四部分使用精确货币表示加总后必须等于公司未来分成收入，守恒差为 0。买断及其他
非分成现金不属于目标。

## 预测时可见性

- 核心人口只使用预测起点可见现金选择；Core90 为主开发人口，Core80 为敏感性分析。
- 未来新增作品只输出组合金额，不输出或推测具体作品身份、渠道或上线时间。
- 现有作品新增渠道只输出组合金额，不预测具体作品将进入哪个渠道。
- 三级分类只用于报告与诊断，不是金额倍率。
- 未来实际 TopN 只用于事后归因，不能成为特征或人口选择依据。

## 冻结实验

- `L0`：冻结同案例参考；
- `L1`：现有核心作品冻结 3/6 月人工规则；
- `L2`：现有长尾组合；
- `L3`：未来新增作品组合；
- `L4`：现有作品新增渠道组合；
- `L5A/L5B`：两种冻结 12 月结构；
- `L6A/L6B`：公司级与目录年龄分层的 36 月直接留存；
- `L7`：预登记主候选，3/6 月使用 Core90，12 月使用 `L5B`，36 月使用 `L6A`。

不得根据外层结果替换原始实验臂。

## 长期合同

第 1、2、3 年留存比例都直接相对于预测起点前 12 个月公司分成现金估计。禁止用
作品级 `k` 连续复合，也禁止从第一年比例递归得到第二、三年。

目录年龄带固定为 0–12、13–24、25–60 和 60 个月以上。支持不足时从年龄带收缩到
公司级目录，再收缩到可用成熟历史中位数；资格依据是成熟伪起点、独立时间块、正
金额分母和不确定性，不使用固定作品数门槛。

## 评价与停止规则

使用 M2 评价合同 v2.2 和开发可建模冲销重述 actual。分别评价四个组件、现有目录和
公司总现金，按 3/6/12/36 月、Y1/Y2/Y3、Primary/Strict、年份、独立时间块和
2,000 次适配 cluster bootstrap 报告。

各 horizon 独立判定，不用统一冠军掩盖相反表现。首个完整有效真实账单评价产生后，
停止模型执行；本任务不授权调参、final holdout、later-origin、生产、自动化、
provider、数据库、release、M3 formal 或合并 PR。
