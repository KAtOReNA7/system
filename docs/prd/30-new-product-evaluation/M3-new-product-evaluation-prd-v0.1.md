# M3 新品评估 PRD v0.1

状态：M3-0 至 M3-7 fixture/prototype 开发口径

本 PRD 基于 `docs/prd/06-新品评估.md` 和当前 M2 本地候选 checkpoint。当前阶段允许开发 synthetic fixture/prototype，不代表 M3 formal execution、正式发布或生产审批。

## 1. 定位

M3 面向上线前选题。系统负责把材料、结构化输入、历史对标、作者排位、外部热度和类别曲线转化为新品五年预测、首年预测、评级、风险和回测基准。

## 2. 范围

纳入范围：

- 选题库。
- Word/PPT/PDF/手动录入材料的元数据和结构化确认流程。
- 必填输入 readiness。
- 精准历史对标、同作者修正、类别曲线、热度映射。
- 作者排位。
- 外部数据版本和时效性。
- 五年累计预测区间、五年基准、首年预测、第 1-5 年拆分。
- 新品评级、支撑因素、限制因素、风险。
- 选题与老品一对一关联。
- 首年、三年、五年回测入口。

暂不纳入：

- M3 formal execution。
- 正式写 API、正式导出、正式发布审批。
- 原始材料长期公开存储。
- 生产/共享/staging-like 数据库连接。
- 绕过 M2 readiness 的正式输入使用。

## 3. 必填输入

| 字段 | 要求 |
|---|---|
| 书名 | 必填 |
| 作者 | 必填 |
| 来源 | 必填，区分出版物和原创网文 |
| 完整三级分类 | 必填 |
| 简介 | 必填 |
| 字数 | 必填，用于估计有声体量 |
| 完结状态 | 必填 |
| 阅读/收藏/评分 | 必填，作为热度信号 |
| 同名有声 | 必填 |
| 影视动漫 | 必填 |
| 站外热度 | 必填 |
| 目标渠道 | 必填 |
| 版权期限范围 | 必填 |
| 运营推荐理由 | 必填 |

缺失字段进入 readiness gap，不生成 formal-style 预测结论。

## 4. 预测方法

预测组合：

- 精准历史对标，最终不超过 3 部。
- 同作者修正，同作者作品不占对标名额。
- 类别曲线。
- 外部热度映射。
- 运营对标与系统对标并列保留。

买断收入必须剔除或单列，不混入实销对标口径。

## 5. 输出

- 五年累计预测区间。
- 五年基准值。
- 首年预测。
- 第 1-5 年年度收入、占比、累计和同比。
- 五年和首年渠道结构说明。
- 新品评级。
- 评级调整原因。
- 支撑因素最多 3 条、限制因素最多 3 条、风险最多 3 条。

不输出固定“是否建议开发”结论，不设置资源投入等级。

## 6. 选题与老品关联

- 一个选题只关联一部标准作品。
- 一部标准作品只正式关联一个选题。
- 只有作品产生实销后，运营才补充标准作品 ID。
- 系统检索已有老品并确认，不创建待收入记录。
- 选题仍保留在选题库。

## 7. 回测

上线前最后一次正式新品评估为回测基准。首年、三年、五年形成结论：

- 高于预测区间。
- 落入预测区间，并标记靠近上限、接近基准或靠近下限。
- 低于预测区间。

重要偏差进入异常清单和后续 M4 校准。

## 8. 验收标准

当前 M3 fixture/prototype 验收：

- API 返回 synthetic fixture，并显式标记 `notForFormalDecision`。
- 只读管理端展示总览、选题库、详情、缺口、回测。
- formal 请求被阻断。
- write-like 路由不可用。
- 不泄露真实作品名、作者名、渠道名、原始材料、原始账单行或连接串。

formal M3 验收需另行授权。
