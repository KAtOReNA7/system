# 术语表

**状态：FROZEN**

| 术语 | 定义 |
|---|---|
| 实销金额 | 当前账单中唯一金额字段，也是收入统计、预测、评级和年度目标的唯一金额口径。允许为正数、零或负数。 |
| 原始财务作品 ID | 财务账单中的作品 ID。纯数字表示有声版权，`Y+数字`表示有声成品。 |
| 标准作品 ID | 原始财务作品 ID 的数字主体。例如 `12345` 与 `Y12345` 均归属标准作品 `12345`。 |
| 标准作品 | 老品库、原作级评估、预测、年度目标和选题关联的核心业务对象。 |
| 业务形态 | 有声版权或有声成品。分别保存收入构成和各自首次实销月份。 |
| 标准作品上线时间 | 该标准作品所有业务形态中最早的首笔实销入账月份。 |
| 业务形态首次实销月份 | 某一业务形态第一次出现实销记录的月份。 |
| 新品实销 | 标准作品上线时间位于目标年度的实际实销。后来新增另一业务形态不再次使标准作品成为新品。 |
| 选题 | 尚未产生实销的上线前评估对象。 |
| 老品 | 已产生实销并进入老品库的标准作品。 |
| 账单导入批次 | 一份通过校验并执行正式导入的账单文件所对应的可追溯业务批次。 |
| 业务原子性 | 外部只能看到完整成功的正式导入结果；处理过程可分块进入临时区域，但不能暴露部分正式结果。 |
| 评估任务 | 执行排队、运行、取消、重试等技术流程的后台任务。 |
| 评估尝试 | 一次实际调用评估流程后形成的业务尝试记录，状态仅为“成功”或“失败”。取消或尚未执行的任务不生成评估尝试。 |
| 正式评估结果 | 由成功评估尝试生成的业务结果，状态为当前有效、历史版本或已失效。 |
| 评估异常提醒 | 作品层提醒，表示最近评估尝试失败或当前没有可用正式结果；不是正式评估结果状态。 |
