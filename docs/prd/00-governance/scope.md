# 系统范围与里程碑

**状态：FROZEN**  
**版本：v0.2**

## 系统定位

本系统是有声书运营内部使用的收入分析与决策支持平台。财务系统负责金额事实，本系统负责数据治理、作品主数据、评估、预测、回测、算法校准和年度目标。

## 核心边界

- 未产生实销的对象称为选题，只存在于选题库。
- 已产生实销并完成数据治理的对象称为老品，以标准作品为核心。
- 未产生实销的选题不进入老品库和年度目标。
- 正式评估不直接覆盖；新评估生成新记录。
- 正式投入使用前必须完成 M1 至 M6。

## 里程碑

- **M1 数据基础**：账单、批次、质量检查、渠道、标准作品、基础信息、分类与标签。
- **M2 老品评估**：收入分析、生命周期、预测、评级、建议、回测。
- **M3 新品评估**：材料解析、外部数据、对标、作者排位、预测、评级和回测。
- **M4 校准与修复**：案例、规则、反馈、问题组、Codex 修复、重评和回滚。
- **M5 平台辅助能力**：完整任务中心、通知、邮件、导出、历史对比和监控。
- **M6 年度目标**：下一自然年度实销目标、月度拆分、执行跟踪和复盘。

## M1 工程冻结目标

M1 开发前必须冻结：

- 账单字段与金额口径；
- 文件、任务、批次、临时数据和正式收入之间的业务关系；
- 数据问题与阻断原则；
- 正式导入和撤销的业务原子性；
- 渠道、作品 ID、业务形态和分册归并规则；
- 基础信息、作者、分类与标签的结构机制；
- M1 必需的任务、安全、备份、恢复与一致性检查；
- 可执行验收标准。
