# 05. 老品评估

## 5.1 评估范围

老品是已经产生实销并进入老品库的标准作品。评估面向剩余版权期，不按固定周期自动运行，由运营按需发起；失效修复场景除外。

## 5.2 输入

- 全历史月度实销；
- 近12/24个月及近期收入；
- 渠道和业务形态结构；
- 版权期限；
- 产品状态；
- 分类标签；
- 人工确认的分成账单；买断只作独立审计/评级历史背景，不能进入收入预测；
- 外部热点或重大业务事件；
- 历史运营案例和正式规则。

最终周期和权重必须由真实账单回测确定。

## 5.3 生命周期

- 一部作品同一时间只有一种生命周期类型；
- 可因外界因素在某一时点切换类型；
- 可增加“近期回升”等状态标签；
- 生命周期在前台展示；
- 先基于全渠道判断，必要时参考渠道差异；
- 分类骨架和阈值由全量账单决定。

## 5.4 预测

输出：

- 未来分成收入单点预测；
- 年度预测及总额；
- 主要渠道结构说明；
- 生命周期；
- 当前评级；
- 主要风险；
- 事实型复核提示。

多算法在早期并行回测。若只有一种方法稳定有效，则正式页面只保留有效方法，不展示无意义的实验结果。

## 5.5 评级与复核提示

- 评级：S/A/B/C/D/E，可S+；
- 收入基础等级可作为底层信息，但老品页面是否展示按最终详情设计；
- M2 不输出推广、定价、续约、下架、重录、打包售卖或资源投入等级等运营动作建议；
- 风险和复核提示只陈述需要确认的事实、证据和阻断原因，不替用户作运营决策；
- 历史 fixture/prototype 中的建议字段只用于回归追溯，不得进入当前正式结果、页面或导出；
- 临近到期定义为半年内。

## 5.6 业务形态

有声版权与有声成品分别展示收入构成，最终只输出一个原作级综合评级和预测。M2 不针对任一业务形态自动提出开发或运营动作。

## 5.7 详情页

顶部概览：评级、历史累计实销、剩余版权期预测、生命周期、风险、事实型复核提示和业务形态构成。

收入区：历史分成月度曲线、未来分成预测、模型外买断审计摘要、业务形态切换、生命周期变化和外部事件时间轴。买断摘要不得与预测金额相加。

基础信息与历史记录通过页签或折叠区域展示。

## 5.8 失效与重评

- 数据错误、归并变化、规则变化等由AI判断必须失效或建议重评；
- 必须失效时，旧结果前台隐藏；
- 自动发起重评并通知结果；
- 自动重评失败时保持失效并进入异常清单。

## 5.9 回测

使用历史分成账单固定时间点，以前段分成收入预测后段分成收入，并比较实际结果。
按生命周期、分类、收入规模、canonical 渠道和收入模式分别验证。核心指标需综合
WAPE、bias、长周期、segment、risk–coverage、区间校准和业务损失。全部买断现金
排除在特征、标签、actual 和预测之外；pure-buyout 必须 null abstain。
