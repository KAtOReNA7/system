# M1 数据基础概览

**状态：FROZEN**

## 目标

建立可信、可追溯、可撤销、可恢复的数据底座。M1 完成后，完整真实账单可以经过质量检查、问题处理和业务原子性导入，形成标准作品、渠道和分类标签主数据，为后续评估提供唯一可信输入。

## 核心对象

- 上传任务；
- 导入文件；
- 临时解析记录；
- 数据问题记录；
- 人工处理决定；
- 账单导入批次；
- 正式收入记录；
- 统一渠道与渠道别名；
- 标准作品与业务形态；
- 历史分册 ID 隐藏映射；
- 作者与作者别名；
- 分类体系版本、分类节点、标签库版本与标签；
- 恢复点和撤销记录。

## 外部可见原则

- 解析、校验和清洗可以分块执行。
- 正式数据只有在整个批次满足提交条件后才对外可见。
- 失败时不得留下部分正式收入或部分主数据变更。
- 所有评估在基础数据问题解决前均被阻断。
