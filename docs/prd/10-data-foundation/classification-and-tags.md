# 分类与标签机制

**状态：结构 FROZEN；具体分类树和标签值 PENDING-DATA**

## REQ-CLASS-001 主分类

- 每部标准作品只有一条主分类路径。
- 一级、二级、三级均为必填。
- 一级区分出版物与原创网文。
- 出版物和原创网文使用不同二、三级分类体系。
- 允许三级兜底节点。
- 出版物与网文不能仅因辅助标签相似跨一级来源对标。

## REQ-CLASS-002 标签体系

- 辅助内容标签和特殊属性标签分别保存。
- 两者均来自固定标签库，可多选。
- 系统前期运营可以直接修改 AI 生成结果。
- 新增正式标签由开发侧审核并纳入标签库版本。
- 分类和标签变更必须记录版本，并识别受影响评估。
