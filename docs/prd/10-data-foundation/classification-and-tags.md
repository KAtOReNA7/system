# 分类与标签机制

**状态：结构 FROZEN；分类树本地治理口径已确定；正式主数据写入仍需后续授权**

## REQ-CLASS-001 主分类

- 每部标准作品只有一条主分类路径。
- 一级、二级、三级分类均为必填字段。
- 一级分类只允许：出版物、网文。
- 二级、三级分类必须从对应一级分类下的固定分类树选择，不允许自由填写。
- 出版物与网文不能仅因辅助标签相似跨一级来源对标。

### 一级分类判定

- 优先参考《授权汇总台账》的“出版or原创”字段：出版对应出版物，原创对应网文。
- 若该字段缺失，可按匹配来源兜底：从《数字版权台账》命中的作品判为出版物；从《原创全库》或《原创全库2》命中的作品判为网文。
- 多来源冲突或无法判定时进入人工确认，不得强行写入正式主数据。

## REQ-CLASS-002 辅助标签

- 辅助标签不再作为普通分类字段自动审查，不与一级、二级、三级分类混填。
- 辅助标签用于记录明显特殊项目加值，例如影视、动画、游戏、漫画、奖项等。
- 系统只能根据各渠道或平台作品名称、授权资料中的强信号生成候选；候选必须由人工添加或核对后才能作为正式标签使用。
- 无强信号时不生成辅助标签候选，不得凭作品类型或普通分类推断辅助标签。

### 辅助标签候选库

- 影视类：电视剧待播、电视剧已播、电影待上映、电影已上映、影视已启动。
- IP类：动画已播、动画待播、动画、游戏、漫画、广播剧。
- 特殊类型：耽美、女性主义。
- 奖项：雨果奖、星云奖、诺贝尔文学奖、茅盾文学奖、直木奖、奥斯卡、戛纳、戛纳电影节、柏林电影节、银河奖、布克文学奖、日本书店大奖、这本推理小说了不起、都柏林文学奖。
- 国家：日本、韩国、美国、冰岛、奥地利、南非、希腊等。国家标签不是封闭枚举，可按明确证据增加其他中文国家名。
- 来源平台：晋江。

### 国家标签候选规则

- 国家标签属于辅助标签，不属于一级、二级、三级分类，也不属于作者或版权字段。
- 系统仅在平台作品名称或授权资料中出现明确国家全称、规范括号简称等强信号时生成候选。
- 国家候选必须由人工添加或核对；不得仅凭题材、语言、作者姓名或模糊字词自动采用。
- 同一作品存在多国强信号时可保留多个候选，但必须人工确认其实际业务含义。

## REQ-CLASS-003 特殊属性标签

- 特殊属性标签与辅助标签分开管理。
- 特殊属性标签用于记录与作品运营、版权或评估解释有关的结构化特殊状态。
- 特殊属性标签不得替代主分类，也不得用于跨一级分类对标。
- 新增正式标签必须纳入标签库版本，并记录启用、停用和受影响作品。
- 当前 M1/M2 人工数据收口不启用独立的特殊属性标签字段，也不把该字段作为分类与标签收口阻断项。
- 后续只有在用户明确新增结构化状态规则、候选库和版本边界时，才启动特殊属性标签的独立治理；不得把它重新混入当前一级、二级、三级分类或辅助标签核对表。

## REQ-CLASS-004 最终基础表确认

- 分类与辅助标签的最终人工入口必须是覆盖全部账单作品的一张完整基础表，按出版物、网文分为两个主阅读页。
- 系统必须自动带入较早人工核对文件中的最新有效值；已确认值不得再次生成为待补项。
- 用户直接修改一级、二级、三级分类和辅助标签的最终采用值，不再填写“候选值/采用值”重复列。
- 全量检查完成后，用户只需做一次整体确认；确认后的表作为后续本地分类与标签基础候选。
- 该确认仍是本地文件级收口，不代表正式主数据已写入。
- 2026-07-10 用户已确认全量基础大表；最终本地候选覆盖 3053 部作品，出版物 1195 部、网文 1858 部，分类与辅助标签人工缺口为 0。
- 用户确认后新增的分类和标签必须同步进入受控词表版本，后续以固定基础表为准，不得退回较早系统候选。

## M1/M2 本地治理边界

- 当前规则可用于本地文件级 staging、人工确认包和 M2 readiness 重算。
- 当前规则不等于正式主数据已写入。
- 正式写入分类和标签前，必须保留候选来源、候选理由、人工确认状态和变更版本。
- 分类和标签治理必须与作者、版权日期、作品状态、音频版权状态分开处理。
- 作者、版权日期、作品状态和音频版权状态不得重新出现在分类与标签最终基础表中；作者仅可作为作品识别信息展示。
