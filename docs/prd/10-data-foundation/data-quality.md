# 数据质量与问题处理

**状态：FROZEN；扩展异常模式为 PENDING-DATA**

## REQ-DQ-001 问题阻断

所有疑似重复、作品冲突、渠道冲突、分册冲突和其他可能影响收入正确性的问题，在正式导入前必须解决。未确认问题不得进入正式收入库或评估。

## REQ-DQ-002 重复与冲抵

- 已知重复模式集中在同一文件内，同一月份、渠道和作品出现多条相同实销记录。
- 不同文件中出现同一作品不自动视为重复。
- 零值和负值通常代表合法冲抵，必须保留并参与求和。
- 明确重复可根据已验收规则自动处理；疑似重复必须进入问题清单。
- 扩展异常模式由真实账单分析确定，并通过规则版本管理。

## REQ-DQ-003 本地修改优先

- 问题较少时可逐项确认。
- 问题较多或模式复杂时，系统生成问题文件和清洗报告，整份退回运营本地修改后重新上传。
- 系统不得为追求“一站式”而在巨型账单上建设大量低效手工编辑能力。

## 问题记录最小字段

- 问题类型；
- 文件和原始行定位；
- 涉及字段与原始值；
- 阻断级别；
- 系统判断依据；
- 人工处理决定；
- 处理时间；
- 使用的清洗规则版本。

## 待真实数据确定

- 完整重复模式；
- 文件规模边界；
- 错误过多时退回整份文件的判断规则；
- 规则自动化阈值。
