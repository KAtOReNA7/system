# 评估共同规则

**状态：FROZEN**

## REQ-EVAL-001 评估任务与评估尝试分离

- 评估任务承担排队、运行、取消、重试等技术流程。
- 评估尝试只记录实际执行后的业务结果，状态仅为：`成功`、`失败`。
- 任务在执行前被取消时，不生成评估尝试。
- 同一次任务因临时错误自动重试时，可记录多个失败尝试和最终成功尝试；正式结果只由成功尝试生成。

## REQ-EVAL-002 正式评估结果状态

正式评估结果状态仅为：

- 当前有效；
- 历史版本；
- 已失效。

失败评估尝试不生成正式评估结果。

## REQ-EVAL-003 评估异常提醒

“评估异常”是作品或选题层的提醒，不是正式评估结果状态。以下情况可产生提醒：

- 最近一次评估尝试失败；
- 当前评估已失效且自动重评失败；
- 当前没有可用正式评估结果。

## REQ-EVAL-004 重评与版本

- 新正式结果成为当前有效。
- 上一当前有效结果转为历史版本。
- 基础数据错误导致的原结果标记已失效并保留原因。
- 旧失效结果不在普通前台展示。
- 已发布年度目标不回溯修改，滚动预计使用新的当前有效结果。
