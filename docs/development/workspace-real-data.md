# 真实作品与账单只读接入

本轮接通工作台、列表和档案详情，研究继续只读。真实资料浏览通过不等于正式导入、
基础信息应用、M1 全量验收或模型发布。

## 当前 PRD 对齐

以 docs/prd/10-data-foundation/ 的稳定需求为准，总体旧稿仅供追溯。

| 需求 | 本轮实现与边界 |
| --- | --- |
| REQ-WORK-001/002/005 | 财务数字主体作为作品编号；Y 前缀对应有声成品；现金类型单列。待确认分册候选不执行归并。 |
| REQ-WORK-003/004/008 | 首次正数实销月；作者、三级分类、作品来源和版权日期只按精确编号唯一值读取。缺失或冲突留空。 |
| REQ-DATA-IMPORT-001/004 | 复用人工分成/买断成员关系校验器；逐行多重集、逐月与总额守恒后生成只读缓存。 |
| REQ-DATA-IMPORT-006 | 账单最大月与人工完整月分开，未完整月份仍可事实追溯。 |
| REQ-DQ-001/002 | 零、负数保留，未观察月为空；候选和主数据问题必须可见。 |
| 根 AGENTS / M2 | 买断只作审计，预测为 null；不改变研究结果、业务门禁或执行权限。 |

## 使用

在有私有权威资料的仓库根执行：

```powershell
npm run doctor:capability -- workspace-local-readonly
npm run workspace:prepare:local
npm run build
$env:M1_WORKSPACE_SOURCE = 'local_snapshot'
npm start
```

访问 http://127.0.0.1:3000/workspace/。使用另外的本地私有源仓库根时，
准备命令传入 -- --source-root <私有源仓库根>，启动设置 M1_WORKSPACE_SOURCE_ROOT
为同一位置。这是运行时配置，不写进实现或长期业务合同。

默认 formal 仍使用既有 database 读接口。local_snapshot 必须显式选择，HTTP 参数不能切换。
fixture 继续使用独立入口。无私有资料的 clone 仍可安装、测试、启动 /health 与查看公共研究。

## 来源与缓存

总账与拆分账单未能对齐时，严格准备会停止，不覆盖原有效缓存。
可显式选择独立原始核对模式：

```powershell
npm run workspace:audit:local
$env:M1_WORKSPACE_SOURCE = 'local_audit'
npm start
```

它使用独立 audit.json 与 RAW_LEDGER_AUDIT 类型，页面持续显示“对账尚未通过”。
schema、类型纯度、拆分不重叠必须实际通过；守恒失败或未执行检查明确保留，
金额仅用于原始记录核对，不进入正式收入库、财务汇总、预测或验收。
它不能在严格模式失败后自动启用；缺源、非法编号、非数值金额及源变化仍然阻断。

人工拆分的三份账本是现金类型权威，总账只作守恒；已确认渠道表提供规范渠道；
作品台账按精确编号读取，跨源冲突不自动裁决。分册候选只作问题提示。

分类优先使用 PRD 指定的全量人工确认基础表，并校验受控三级分类树，不退回旧系统候选。
版权日期优先使用数字版权台账；同一权威源出现多组值时保留冲突，低优先资料不覆盖它。

输出 data/private-output/workspace/current.json 是可再生缓存，禁止提交；
缺失、损坏或过期时重新从源生成，不需要旧研究输出或 receipt。
生成器只读权威源，校验通过后原子替换整包，失败不覆盖旧缓存。
它不调用模型、数据库、provider 或历史评价 runner。

快照绑定实际读取源的摘要和文件状态。Node 首次读取重算源 SHA256，
后续请求检查文件状态；这是普通修改检测，不是对恶意管理员伪造本机文件的证明。
快照同时绑定当前生成器与三账本校验器摘要；旧缓存或实现变化后需要重新准备。
逐行差异、同六字段不同金额记录和中文待确认问题单使用 [三账本核对入口](ledger-reconciliation.md)。
真实数据与源路径不进入静态资源目录，HTTP 只返回白名单字段。

## 页面口径

近 12 月“已记录分成现金”按完整月结束的窗口求和，同时显示观察月覆盖；
缺月不补零，无同期记录为 null，合法观测零为 0。负数以精确明细展示。
按账单入账月显示净额，不运行模型的历史冲销重述；买断单列审计。

“已观察完整月”只计处于完整范围且确有账单记录的不同月份，
不等于首末跨度、渠道月月齐全或动态 Core80 资格。
当前公开人工完整月口径为 2026-04，2026-05 不完整；不能自动取最大月份推进。

详情展示作品资料、规范渠道同期现金、买断审计、全部月份和待确认问题。
账单名称不唯一时，标准名称仍为空；原账单识别名称可搜索、逐项查看，并明确标记待确认。
缺源、损坏、过期分别报错，不显示空库或演示数据。公共研究页独立可读。

## 验证

合成测试覆盖拆分不守恒、零负数、缺月、混合现金、纯买断、候选不应用、
来源变更/越界/损坏、组合隔离和浏览器交互。真实本机核对只保留状态与守恒结论，
不把私有行、作品名、金额或本机路径提交 GitHub。
执行根目录九项门禁，并在无私有资料与凭据的新克隆中重复。
