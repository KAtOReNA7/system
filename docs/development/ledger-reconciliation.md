# 三账本差异核对与程序校验

本入口用于原始资料核对，不执行正式导入、不修改账单、不推断现金类型，也不调用
模型、数据库或 provider。人工分成/买断成员关系仍是现金类型权威；总账只作守恒。

## PRD 与当前合同

- REQ-DATA-IMPORT-001：只使用实销金额；合法零值和负值保留，缺失不能当作零。
- REQ-DATA-IMPORT-004、REQ-DQ-001：未解决的差异继续阻断正式收入与评估，不接受
  无依据尾差或人工调整金额凑平。
- REQ-DQ-002/003：同作品或同月同渠道不能直接判为重复；复杂问题保留来源与原值，
  业务确认后修改原始资料的新版本，再重新核对。
- 三账本成员关系和七项校验来自根 AGENTS 与
  config/m2-current-human-ledger-partition.v0.1.json，不另造 M1 需求编号。

## 使用

在存有私有权威源的仓库根执行：

```powershell
npm run doctor:capability -- workspace-ledger-reconciliation
npm run workspace:reconcile:local
```

也可以传入 `-- --source-root <私有源仓库根>`。新入口属于 restricted-local，
只有用户授权的本地只读核对才使用。缺少权威源不影响公共开发和服务器健康检查。

输出位于 Git ignored 的 data/private-output/workspace-reconciliation/：
current.json 保留来源指纹、当前执行代码身份、七项检查、逐月差额、差异签名和
全部同签名源行；current.txt 提供中文问题单、同六字段其他金额记录及“你的填写”。
JSON 是本次诊断的机器记录，TXT 是可重建的展示；二者应核对生成时间。
两个文件分别原子写入，不构成两文件事务；诊断失败返回非零，不把未完成检查写成通过。
代码文件摘要绑定实际执行内容（包括尚未提交的修改）；gitHead 只表示执行时仓库提交，
不能用它替代代码文件摘要。
退出码 0 表示分区守恒，2 表示已生成差异报告，1 表示读取或校验失败。

报告中的差额统一为“分成加买断减总账”。金额使用 Decimal，不做舍入、截断、
吸收尾差或反向补行。输出保留每条差异的次数和同签名全部出现位置；多个完全相同
实例无法仅靠文件内容判定哪一个是错误行。前六字段相同但金额不同的记录只是
待核对组，不能据此自动合并、删行或覆盖金额。

来源摘要、大小和修改时间在读取前后核对。生成器只读取文件；日期元数据不能证明
具体记录的人工编辑人、编辑时间或编辑原因。私有明细、金额、作品/渠道标识和
机器路径不写入公共文档、测试、PR 或静态站点。

## 本轮程序修复

唯一的 analyze_partition 实现同时服务严格校验、显式原始核对和差异报告，
validate_partition 保留原成功返回结构和七项检查，不再维护一份平行守恒逻辑。

- 数值年月 YYYYMM 按真实年月解释，避免落入 1970 年的纳秒日期；非法月份拒绝。
- 任一账本缺失、非法或非有限金额拒绝，不能把总账空金额与拆分中的零匹配。
- 真实源表头在投影前校验，重复表头拒绝；三表列集合不一致不能宣称 schema_equal。
  按列名匹配，因此表头排列变化本身不构成业务差异。
- 字面 NA/N/A 等文本保留，不与真正空值合并；既有合法日期、有限金额、零和负值
  保持精确签名语义。
- 工作台复用同一分析结果，额外记录与总账未拆分记录均保留出处，现金类型不推断。
- 读取配置前先取源摘要，避免先使用旧配置、再绑定新文件摘要。
- 工作台缓存绑定当前生成器和三账本校验器摘要与校验版本；实现变化或旧缓存没有
  绑定信息时要求重建，不能继续使用旧校验结论。它不是所有运行依赖的完整收据，
  也不能代替源系统的历史 effectiveAt/availableAt。

修改校验器会自然使引用它的私有派生缓存摘要失效；本轮不回填历史 receipt/digest，
不重跑任何冻结科学评价来消除差异。公开合成测试只验证程序合同，不产生模型成绩。

## 需要业务确认的内容

问题单保留文件、行号、原值、候选对应记录和未决原因。业务确认应至少给出：

| 问题 | 中文选项 | 最少依据 | 你的填写 |
| --- | --- | --- | --- |
| 总账无对应记录而拆分有记录 | 总账漏记 / 拆分误录或误保留 / 其他原因 / 不清楚 | 原始平台账单、财务凭证或经办人明确说明 | |
| 同六字段出现多笔不同金额 | 独立现金记录 / 已包含在另一笔 / 其他原因 / 不清楚 | 支持每笔金额的原始凭证与处理规则 | |

无法确认时保持阻断。不能以金额小、月份不完整、名称像汇总项或计算外观相似为由
删除记录或改变现金类型。用户确认后也应记录依据、确认人、确认时间和规则版本，
形成新的人工复核源版本并重跑七项检查；不是直接应用问题单中的文字决定。
