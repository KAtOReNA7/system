# 研究验收证据与本轮优先级

本轮延续既有方案，调整的是执行顺序：真实资料只读入口和研究摘要基础版已完成，
现在补逐周期、逐粒度的证据缺口及冻结路线说明。研究接口继续只读，不执行模型。

## 昨日五项建议的当前处理

| 建议 | 当前进展与本轮动作 |
| --- | --- |
| 整理业务验收缺口 | 本轮新增四周期乘两粒度的证据矩阵；阈值和登记状态来自业务合同，不能把合同启用写成模型通过。 |
| 研究成果进入只读界面 | 已有基础版，沿用 XG 页面和同一 API，补矩阵、冻结路线和字段级出处，不重复建站。 |
| PSC02 历史权威与程序问题分开 | 展示历史起点权威不可恢复、成功路径未实现和无性能证据三个独立状态；不补造历史时点或重跑。 |
| PSC03 合同与实现一致 | 当前纠正状态优先于旧结果码，冻结原始结果保留但不作为有效候选成绩；不开发修正版或后继模型。 |
| 尊重结束路线后推进产品 | 头部保护尾段修正模型唯一独立结果保留不确定结论与研究结束边界，M1资料核对继续，正式任务链/M3另定范围。 |

M1 原始核对仍保留现金权威未通过的状态。读取源摘要与原子派生快照是输入完整性与
普通修改检测，不等于源系统 historical availableAt，也不等于包含生成代码版本的完整运行收据。
未来数据接收机制应记录真实收到时点及源系统提供的生效/可得时间；未知值不得回填，
现有现金锚历史权威不能靠新采集机制补回。本轮不改私有账单或 M1 快照生成器。

## 验收矩阵的证据身份

作品总额四行只对应现有 Core80 横评中人工锚定可学习全局模型自身可预测案例。
误差、偏差分别与当前合同数值上限对照，金额覆盖、逐周期稳定性和不确定性未在该
同口径摘要中披露，保持 null。案例覆盖不参与金额覆盖计算。

作品×渠道单独列四行。合同目前只登记36个月的部分证据，其余周期应写尚无该周期
渠道门禁登记；不能复制36个月缺项数，不能复制作品总额数值。

合同另有13起点的36个月历史参考窗口，与当前横评36个月行的案例数和评价家族不同。
本轮不把该窗口的分位数、误差集中度或独立时间状态移植进横评行，也不把头部保护
尾段修正模型的独立评价区间当作全局模型四周期区间。未披露只限该摘要，不表示
整个项目从未产生相应历史证据。

## 合同要求与工程验证

| 要求 | 实现与验证 |
| --- | --- |
| 四周期及两个粒度不可混合 | 公共投影明确构造八行；测试核对周期集合、粒度登记和各自来源。 |
| 数值条件不能替代完整验收 | 仅投影数值对照，完整验收不返回通过；测试覆盖超限与缺证据情况。 |
| 缺失不能补零或借用其他窗口 | 同口径缺项固定空值并给出原因，注入其他覆盖/区间字段不能改变当前行含义。 |
| 实验历史与现行权威分开 | 按稳定模型、实验ID唯一选取；PSC03现行纠正状态优先，历史结果另列。 |
| 出处可读且受限 | 只允许固定公开来源 ID；任意路径和继承对象键不得读取。 |
| 只读且不授予执行权限 | 沿用原HTTP组合，研究页不依赖私有资料或数据库；浏览器测试拒绝外部请求和写请求。 |

这些验证针对产品证据呈现与来源合同，不把冻结模型实现重新判为合同一致，
也不提供训练、重跑、独立评价、生产或后继模型授权。

## 使用与验收

既有服务中打开 /workspace/#/research。先看四张历史指标卡，再在“验收证据矩阵”
切换作品总额/作品×渠道，可展开证据身份与来源；研究路线区单列现行状态、历史状态
和执行边界。

遵循根 AGENTS 的九项公共门禁。单测使用公开文件和合成变体，端到端测试通过真实
本地HTTP读取，检查两粒度切换、空值、冻结路线、来源白名单与320像素布局。
冻结模型登记、业务合同、历史指标与私有数据不作修改。
